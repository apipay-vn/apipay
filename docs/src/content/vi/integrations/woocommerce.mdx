# WooCommerce

Plugin ApiPay chuyển khách sang trang thanh toán của ApiPay khi checkout và tự cập nhật đơn khi khách đã thanh toán. Hỗ trợ cả checkout cổ điển và Checkout Block.

ApiPay chỉ hỗ trợ đơn hàng VND.

<Callout type="tip">
Mở **Tích hợp > Web App > WooCommerce** trong dashboard để tải plugin đã cấu hình sẵn.

[Mở WooCommerce trong dashboard](https://my.apipay.vn/vi/integrations/woocommerce)
</Callout>

## Cài đặt plugin

1. Trong dashboard ApiPay, mở **Tích hợp > Web App > WooCommerce**.
2. Chọn tài khoản ngân hàng nhận tiền và tên miền riêng nếu có.
3. Tải `apipay-woocommerce.zip`.
4. Trong WordPress, mở **Plugins > Add New > Upload Plugin** và tải file ZIP lên.
5. Kích hoạt **ApiPay for WooCommerce**.

## Bật phương thức thanh toán

Mở **WooCommerce > Settings > Payments > ApiPay**, bật phương thức thanh toán rồi lưu. Plugin đã điền sẵn thông tin kết nối; không cần sửa.

## Thanh toán thử

1. Đặt một đơn hàng và chọn **Bank transfer via ApiPay** khi checkout.
2. Kiểm tra bạn được chuyển sang trang thanh toán của ApiPay.
3. Chuyển khoản đúng số tiền và nội dung hiển thị.
4. Khi khách chuyển khoản thành công, đơn chuyển sang `processing`.

## Xử lý lỗi

ApiPay gửi thông báo thanh toán đến:

```text
https://your-wordpress-site.com/?wc-api=apipay_woocommerce
```

Nếu đơn chưa cập nhật, hãy kiểm tra:

- Website WordPress truy cập được công khai qua HTTPS.
- Plugin bảo mật hoặc firewall không chặn endpoint `wc-api=apipay_woocommerce`.
- Khóa API trong plugin vẫn đang hoạt động trên dashboard.
