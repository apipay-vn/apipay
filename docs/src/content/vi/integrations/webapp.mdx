# Web App

Tạo yêu cầu thanh toán từ server, chuyển khách đến `payUrl`, rồi nhận kết quả qua redirect hoặc webhook. Không cần cài SDK.

## Trước khi bắt đầu

- Tạo khóa API trong [**Tích hợp > Web App > API Keys**](https://my.apipay.vn/vi/integrations/api-keys).
- Kết nối ít nhất một tài khoản trong **Ngân hàng**.
- Lưu `APIPAY_ACCESS_KEY`, `APIPAY_SECRET_KEY` và `APIPAY_BANK_PUBLIC_ID` vào biến môi trường.
- Chỉ gọi ApiPay từ server, không gọi từ trình duyệt.

## Tạo yêu cầu thanh toán

Sao chép vào code chạy trên server.

<CodeTabs>
```javascript
const API_BASE = "https://app.apipay.vn";

const auth = Buffer.from(
  `${process.env.APIPAY_ACCESS_KEY}:${process.env.APIPAY_SECRET_KEY}`,
).toString("base64");

async function createPayment(params) {
  const response = await fetch(`${API_BASE}/v1/client/payment-requests`, {
    method: "POST",
    headers: {
      Authorization: `Bearer ${auth}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      bankPublicId: process.env.APIPAY_BANK_PUBLIC_ID,
      ...params,
    }),
  });

  if (!response.ok) {
    throw new Error(`ApiPay request failed: ${response.status}`);
  }

  const { data } = await response.json();
  return data;
}

const payment = await createPayment({
  amount: "100000",
  content: "ORDER-001",
  title: "Payment for Order #001",
  redirectUrl: "https://your-site.com/payment/result",
});

console.log(payment.payUrl);
```

```python
import base64
import os

import requests

API_BASE = "https://app.apipay.vn"
AUTH = base64.b64encode(
  f"{os.environ['APIPAY_ACCESS_KEY']}:{os.environ['APIPAY_SECRET_KEY']}".encode()
).decode()


def create_payment(**params) -> dict:
  response = requests.post(
    f"{API_BASE}/v1/client/payment-requests",
    json={"bankPublicId": os.environ["APIPAY_BANK_PUBLIC_ID"], **params},
    headers={"Authorization": f"Bearer {AUTH}"},
    timeout=15,
  )
  response.raise_for_status()
  return response.json()["data"]


payment = create_payment(
  amount="100000",
  content="ORDER-001",
  title="Payment for Order #001",
  redirectUrl="https://your-site.com/payment/result",
)

print(payment["payUrl"])
```

```php
<?php

const API_BASE = 'https://app.apipay.vn';

function createPayment(array $params): array
{
  $auth = base64_encode(getenv('APIPAY_ACCESS_KEY') . ':' . getenv('APIPAY_SECRET_KEY'));

  $ch = curl_init(API_BASE . '/v1/client/payment-requests');
  curl_setopt_array($ch, [
    CURLOPT_POST => true,
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_TIMEOUT => 15,
    CURLOPT_HTTPHEADER => [
      "Authorization: Bearer {$auth}",
      'Content-Type: application/json',
    ],
    CURLOPT_POSTFIELDS => json_encode(['bankPublicId' => getenv('APIPAY_BANK_PUBLIC_ID')] + $params),
  ]);

  $body = curl_exec($ch);
  $status = curl_getinfo($ch, CURLINFO_HTTP_CODE);

  if ($body === false || $status >= 400) {
    throw new RuntimeException("ApiPay request failed: {$status}");
  }

  return json_decode($body, true)['data'];
}

$payment = createPayment([
  'amount' => '100000',
  'content' => 'ORDER-001',
  'title' => 'Payment for Order #001',
  'redirectUrl' => 'https://your-site.com/payment/result',
]);

echo $payment['payUrl'];
```

Kết quả trả về (rút gọn):

```json
{
  "publicId": "APIPAYJSCAF9H23M74K",
  "payUrl": "https://pay.apipay.vn/APIPAYJSCAF9H23M74K",
  "redirectSecret": "a1b2c3d4e5f6..."
}
```

Lưu `publicId` và `redirectSecret` cùng đơn hàng, rồi chuyển khách đến `payUrl`.

## Xử lý kết quả thanh toán

**Redirect:** sau khi thanh toán, khách được đưa về `redirectUrl` kèm tham số `data` và `signature`. Xác minh bằng `redirectSecret` trước khi hiển thị trạng thái đã thanh toán. Xem [Payment Requests API](/vi/api/payment-requests).

**Webhook:** mở **Webhooks** trong dashboard để đăng ký endpoint nhận thông báo thanh toán. Mỗi webhook có header `ApiPay-Signature` để bạn xác minh. Xem [Webhooks](/vi/api/webhooks).

## Trước khi chạy thật

- Mỗi đơn hàng dùng một `content` riêng.
- Xác minh chữ ký redirect và webhook trước khi đánh dấu đơn đã thanh toán.
- Webhook có thể được gửi lặp lại; đảm bảo mỗi đơn chỉ được cập nhật một lần.
- Trả HTTP 200 cho webhook ngay, xử lý việc nặng ở nền.
