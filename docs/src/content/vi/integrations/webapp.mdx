# Web App

Dùng ApiPay client API trong web app của bạn để tạo hosted payment request, chuyển khách đến `payUrl`, rồi nhận kết quả qua redirect hoặc webhook.

Các ví dụ bên dưới là helper nhỏ để dùng trong server-side code. Bạn không cần cài thêm SDK ApiPay riêng.

<Callout type="tip">
Mở **Tích hợp > API Keys** trong dashboard để tạo credentials cho web app tùy chỉnh.

[Mở API Keys trong dashboard](https://my.apipay.vn/vi/integrations/api-keys)
</Callout>

## Trước khi bắt đầu

- Tạo API key trong **Tích hợp > API Keys**.
- Kết nối ít nhất một tài khoản ngân hàng đang hoạt động trong **Tài khoản ngân hàng**.
- Lưu `accessKey`, `secretKey` và `bankPublicId` mặc định trong environment variables.
- Không gọi ApiPay bằng secret credentials từ code chỉ chạy trong browser.

## Helper

```javascript
const API_BASE = "https://app.apipay.vn";

function apipayAuth(accessKey, secretKey) {
	const token = Buffer.from(`${accessKey}:${secretKey}`).toString("base64");
	return `Bearer ${token}`;
}

async function createApiPayPayment({
	accessKey,
	secretKey,
	bankPublicId,
	amount,
	content,
	title,
	redirectUrl,
}) {
	const response = await fetch(`${API_BASE}/v1/client/payment-requests`, {
		method: "POST",
		headers: {
			Authorization: apipayAuth(accessKey, secretKey),
			"Content-Type": "application/json",
		},
		body: JSON.stringify({
			bankPublicId,
			amount,
			content,
			title,
			redirectUrl,
		}),
	});

	if (!response.ok) {
		throw new Error(`ApiPay request failed: ${response.status}`);
	}

	const result = await response.json();
	return result.data;
}

const payment = await createApiPayPayment({
	accessKey: process.env.APIPAY_ACCESS_KEY,
	secretKey: process.env.APIPAY_SECRET_KEY,
	bankPublicId: process.env.APIPAY_BANK_PUBLIC_ID,
	amount: 100000,
	content: "ORDER-001",
	title: "Payment for Order #001",
	redirectUrl: "https://your-site.com/payment/result",
});

console.log(payment.payUrl);
```

```python
import base64
import os
import requests

API_BASE = "https://app.apipay.vn"


def apipay_auth(access_key: str, secret_key: str) -> str:
    token = base64.b64encode(f"{access_key}:{secret_key}".encode()).decode()
    return f"Bearer {token}"


def create_apipay_payment(
    *,
    access_key: str,
    secret_key: str,
    bank_public_id: str,
    amount: int,
    content: str,
    title: str,
    redirect_url: str,
) -> dict:
    response = requests.post(
        f"{API_BASE}/v1/client/payment-requests",
        json={
            "bankPublicId": bank_public_id,
            "amount": amount,
            "content": content,
            "title": title,
            "redirectUrl": redirect_url,
        },
        headers={
            "Authorization": apipay_auth(access_key, secret_key),
            "Content-Type": "application/json",
        },
        timeout=15,
    )
    response.raise_for_status()
    return response.json()["data"]


payment = create_apipay_payment(
    access_key=os.environ["APIPAY_ACCESS_KEY"],
    secret_key=os.environ["APIPAY_SECRET_KEY"],
    bank_public_id=os.environ["APIPAY_BANK_PUBLIC_ID"],
    amount=100000,
    content="ORDER-001",
    title="Payment for Order #001",
    redirect_url="https://your-site.com/payment/result",
)

print(payment["payUrl"])
```

```php
<?php

use Illuminate\Support\Facades\Http;

$apiBase = 'https://app.apipay.vn';

function apipayAuth(string $accessKey, string $secretKey): string
{
    $token = base64_encode("{$accessKey}:{$secretKey}");
    return "Bearer {$token}";
}

function createApipayPayment(
    string $accessKey,
    string $secretKey,
    string $bankPublicId,
    int $amount,
    string $content,
    string $title,
    string $redirectUrl,
): array {
    global $apiBase;

    $response = Http::withHeaders([
        'Authorization' => apipayAuth($accessKey, $secretKey),
        'Content-Type'  => 'application/json',
    ])->post("{$apiBase}/v1/client/payment-requests", [
        'bankPublicId' => $bankPublicId,
        'amount'       => $amount,
        'content'      => $content,
        'title'        => $title,
        'redirectUrl'  => $redirectUrl,
    ]);

    if ($response->failed()) {
        throw new \RuntimeException('ApiPay request failed: ' . $response->status());
    }

    return $response->json('data');
}

$payment = createApipayPayment(
    accessKey: env('APIPAY_ACCESS_KEY'),
    secretKey: env('APIPAY_SECRET_KEY'),
    bankPublicId: env('APIPAY_BANK_PUBLIC_ID'),
    amount: 100000,
    content: 'ORDER-001',
    title: 'Payment for Order #001',
    redirectUrl: 'https://your-site.com/payment/result',
);

echo $payment['payUrl'];
```

Sau khi tạo đơn hàng, chuyển khách đến `payUrl`.

## Xử lý kết quả thanh toán

Khi bạn gửi `redirectUrl`, ApiPay sẽ đưa khách về website của bạn sau thanh toán kèm query parameters đã ký. Hãy lưu `redirectSecret` từ response tạo payment request cùng với đơn hàng để trang kết quả kiểm tra được payload trả về.

Để nhận cập nhật server-to-server, tạo webhook trong **Tích hợp > Webhooks**. Khi endpoint nhận payment event tương ứng, cập nhật trạng thái đơn hàng trong hệ thống của bạn.

## Checklist production

- Tạo `content` duy nhất cho từng đơn hàng.
- Lưu ApiPay payment request ID và `redirectSecret` cùng đơn hàng.
- Kiểm tra signed redirect payload trước khi hiển thị trạng thái đã thanh toán.
- Xử lý webhook theo kiểu idempotent để delivery trùng lặp không cập nhật đơn hàng hai lần.
- Trả HTTP 200 từ webhook route thật nhanh, rồi xử lý tác vụ nặng ở background.
