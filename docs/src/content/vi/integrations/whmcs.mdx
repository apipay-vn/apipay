# WHMCS

Module ApiPay cho phép khách thanh toán hóa đơn WHMCS bằng chuyển khoản ngân hàng qua trang thanh toán của ApiPay. Hóa đơn tính bằng VND.

<Callout type="tip">
Mở **Tích hợp > Web App > WHMCS** trong dashboard để tải module đã cấu hình sẵn.

[Mở WHMCS trong dashboard](https://my.apipay.vn/vi/integrations/whmcs)
</Callout>

## Trước khi bắt đầu

- Tạo khóa API trong **Tích hợp > Web App > API Keys**.
- Kết nối ít nhất một tài khoản trong **Ngân hàng**.
- Tùy chọn: xác minh [tên miền riêng](/vi/custom-domains) cho trang thanh toán.

## Tải module

1. Trong dashboard ApiPay, mở **Tích hợp > Web App > WHMCS**.
2. Chọn tài khoản ngân hàng nhận tiền và tên miền riêng nếu có.
3. Tải `apipay-whmcs.zip`.

## Cài đặt trong WHMCS

1. Giải nén ZIP vào thư mục gốc của WHMCS. Các file sẽ nằm trong `modules/gateways/` và `modules/gateways/callback/`.
2. Mở **WHMCS Admin > System Settings > Payment Gateways**.
3. Kích hoạt **ApiPay Gateway**.
4. Kiểm tra thông tin đã điền sẵn, không cần sửa, rồi lưu.

## Thanh toán thử

1. Tạo một hóa đơn và chọn **ApiPay** làm phương thức thanh toán.
2. Kiểm tra khách được chuyển sang trang thanh toán của ApiPay.
3. Chuyển khoản đúng số tiền và nội dung hiển thị.
4. Khi khách chuyển khoản thành công, hóa đơn được đánh dấu đã thanh toán trong WHMCS.

## Xử lý lỗi

Nếu hóa đơn chưa cập nhật, hãy kiểm tra:

- Website WHMCS truy cập được công khai qua HTTPS, firewall hoặc quy tắc bảo mật không chặn callback.
- Khóa API trong WHMCS vẫn đang hoạt động trên dashboard.
- Nếu dùng tên miền riêng, tên miền đó đã được xác minh.
