# WHMCS

Module ApiPay WHMCS cho phép khách thanh toán hoá đơn WHMCS bằng chuyển khoản ngân hàng VND qua trang thanh toán hosted của ApiPay. File ZIP tải từ dashboard đã điền sẵn API credentials, tài khoản ngân hàng đã chọn và tên miền riêng nếu có.

## Trước khi bắt đầu

- Tạo API key trong **Tích hợp > API Keys**.
- Kết nối ít nhất một tài khoản ngân hàng đang hoạt động trong **Tài khoản ngân hàng**.
- Tuỳ chọn: xác minh tên miền thanh toán riêng trong **Hướng dẫn Dashboard > Tên miền riêng**.
- Đảm bảo website WHMCS có thể nhận callback công khai qua HTTPS.

## Tải module

1. Trong dashboard ApiPay, mở **Tích hợp > WHMCS**.
2. Chọn tài khoản ngân hàng đang hoạt động để nhận thanh toán hoá đơn.
3. Có thể chọn thêm tên miền riêng đã xác minh cho trang thanh toán hosted.
4. Tải `apipay-whmcs.zip`.

## Cài đặt trong WHMCS

1. Giải nén ZIP vào thư mục gốc của WHMCS.
2. Kiểm tra các file nằm trong `modules/gateways/` và `modules/gateways/callback/`.
3. Mở **WHMCS Admin > System Settings > Payment Gateways**.
4. Kích hoạt **Apipay Gateway**.
5. Kiểm tra API URL, Partner Code, Access Key, Secret Key, Bank Account ID và tên miền riêng nếu có.
6. Lưu cấu hình gateway.

## Test thanh toán

1. Tạo hoá đơn test bằng VND.
2. Chọn **ApiPay** làm phương thức thanh toán.
3. Kiểm tra WHMCS chuyển khách sang trang thanh toán hosted của ApiPay.
4. Chuyển khoản đúng số tiền và đúng nội dung hiển thị.
5. Sau khi ApiPay xác nhận giao dịch, hoá đơn được đánh dấu đã thanh toán trong WHMCS.

## Xử lý lỗi

Nếu hoá đơn chưa cập nhật, hãy kiểm tra:

- Website WHMCS truy cập công khai được qua HTTPS.
- Gateway ApiPay đã được kích hoạt trong WHMCS.
- API key trong WHMCS khớp với API key đang hoạt động trên dashboard.
- Tài khoản ngân hàng đã chọn đang hoạt động trong ApiPay.
- Số tiền hoá đơn dùng VND.
- Firewall hoặc rule bảo mật không chặn callback endpoint của WHMCS.
- Nếu chọn tên miền riêng, tên miền đó đã được xác minh và đang hoạt động trong ApiPay.
