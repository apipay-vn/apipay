# Vibe Code

Vibe Code tạo system prompt để dùng với AI coding assistant như Claude Code, Cursor và Antigravity. Prompt này hướng dẫn assistant thêm payment requests, chuyển hướng thanh toán và webhook ApiPay vào codebase của bạn.

<Callout type="tip">
Mở **Tích hợp > Vibe Code** trong dashboard để tạo prompt với tài khoản ngân hàng đã chọn.

[Mở Vibe Code trong dashboard](https://my.apipay.vn/vi/integrations/vibe-code)
</Callout>

## Trước khi bắt đầu

- Tạo API key trong **Tích hợp > API Keys**.
- Kết nối ít nhất một tài khoản ngân hàng đang hoạt động trong **Tài khoản ngân hàng**.
- Xác định nơi app xử lý checkout, trang kết quả thanh toán và webhook routes.

## Tạo prompt

1. Trong dashboard ApiPay, mở **Tích hợp > Vibe Code**.
2. Chọn tài khoản ngân hàng đang hoạt động để dùng mặc định cho payment requests.
3. Kiểm tra system prompt vừa tạo.
4. Sao chép prompt và dán vào coding assistant của bạn.
5. Cung cấp ApiPay `accessKey` và `secretKey` cho assistant qua environment variables hoặc local secrets.

## Prompt bao gồm gì

Prompt sẽ yêu cầu assistant:

- Phân tích cấu trúc dự án và pattern API đang dùng.
- Thêm xác thực ApiPay bằng credentials base64 `accessKey:secretKey`.
- Tạo payment request qua ApiPay client API.
- Chuyển khách đến `payUrl` trong response.
- Thêm webhook handler để nhận thông báo thanh toán.
- Giữ credentials trong environment variables, không đưa vào source code.

## Checklist triển khai

Sau khi assistant chỉnh code, hãy kiểm tra:

- Checkout flow tạo payment request với `bankPublicId` đã chọn.
- Khách được chuyển sang trang thanh toán hosted của ApiPay.
- Trang success hoặc result xử lý được redirect từ ApiPay.
- Webhook endpoint trả HTTP 200 nhanh.
- API credentials được lưu trong deployment secrets.

## Xử lý lỗi

Nếu không thấy prompt mới, hãy kiểm tra:

- Bạn có ít nhất một tài khoản ngân hàng đang hoạt động.
- Bạn đã tạo API key.
- Tài khoản ngân hàng đã chọn vẫn tồn tại và đang hoạt động.
