# Vibe Code

Vibe Code tạo sẵn prompt để dán vào trợ lý lập trình AI (Claude Code, Cursor…) giúp tích hợp ApiPay vào dự án: tạo yêu cầu thanh toán, chuyển khách đến trang thanh toán và nhận webhook.

<Callout type="tip">
Mở **Tích hợp > Web App > Vibe Code** trong dashboard để tạo prompt.

[Mở Vibe Code trong dashboard](https://my.apipay.vn/vi/integrations/vibe-code)
</Callout>

## Trước khi bắt đầu

- Tạo khóa API trong **Tích hợp > Web App > API Keys**.
- Kết nối ít nhất một tài khoản trong **Ngân hàng**.

## Tạo prompt

1. Trong dashboard ApiPay, mở **Tích hợp > Web App > Vibe Code**.
2. Chọn tài khoản ngân hàng mặc định cho yêu cầu thanh toán.
3. Sao chép prompt và dán vào trợ lý lập trình AI.
4. Cung cấp `accessKey` và `secretKey` qua biến môi trường, không dán vào prompt hay mã nguồn.

## Prompt hướng dẫn trợ lý

- Đọc cấu trúc dự án và cách gọi API hiện có.
- Tạo yêu cầu thanh toán qua API của ApiPay.
- Chuyển khách đến `payUrl` trong kết quả trả về.
- Thêm endpoint nhận webhook thanh toán.

## Kiểm tra sau khi tích hợp

- Bước thanh toán tạo yêu cầu thanh toán với `bankPublicId` đã chọn.
- Khách được chuyển sang trang thanh toán của ApiPay.
- Trang kết quả xử lý được khi khách quay lại từ ApiPay.
- Endpoint webhook trả HTTP 200 ngay.

## Xử lý lỗi

Nếu chưa tạo được prompt, hãy kiểm tra:

- Đã tạo khóa API.
- Tài khoản ngân hàng đã chọn vẫn tồn tại và đang hoạt động.
