# Ngân hàng hỗ trợ

ApiPay hỗ trợ hầu hết các ngân hàng lớn tại Việt Nam.

## Danh sách ngân hàng

| Mã   | Tên ngân hàng | Loại | Hỗ trợ     |
| ---- | ------------- | ---- | ---------- |
| ACB  | ACB           | Bank | ✓          |
| MB   | MB Bank       | Bank | ✓          |
| BIDV | BIDV          | Bank | ✓          |
| VCB  | Vietcombank   | Bank | Sắp Ra Mắt |
| ICB  | VietinBank    | Bank | Sắp Ra Mắt |

## Mã ngân hàng (Bank Codes)

Khi tạo payment link anonymous, sử dụng mã ngân hàng:

```json
{
  "bankCode": "MB",
  "accountNumber": "0123456789"
}
```

## Lấy danh sách ngân hàng

```bash
GET /v1/banks
```

### Response

```json
{
  "data": [
    {
```

## Supported QR Formats

ApiPay tạo QR code theo chuẩn VietQR, tương thích với tất cả các ngân hàng:

- **VietQR** - Chuẩn QR của VietQR API
- **Bank Transfer** - Thông tin chuyển khoản truyền thống

Người dùng có thể quét bằng:

- App ngân hàng (Vietcombank Mobile, MB Bank, ACB, etc.)
- App thanh toán (VietQR, MoMo, ZaloPay, etc.)
