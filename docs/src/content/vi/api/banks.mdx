# Quản lý ngân hàng

Trang này mô tả API thực tế dùng để client kết nối, xác thực và quản lý tài khoản ngân hàng trên ApiPay.

Base route:

```bash
/v1/client/banks
```

## Mã ngân hàng hợp lệ

Sử dụng các mã `bankShortName` đúng với logic backend:

| Mã     | Ngân hàng   | Trạng thái |
| ------ | ----------- | ---------- |
| `ACB`  | ACB         | Hỗ trợ     |
| `BIDV` | BIDV        | Hỗ trợ     |
| `MBB`  | MB Bank     | Hỗ trợ     |
| `OCB`  | OCB         | Hỗ trợ     |
| `ICB`  | VietinBank  | Sắp ra mắt |
| `VCB`  | Vietcombank | Sắp ra mắt |

## 1. Kết nối tài khoản ngân hàng

```bash
POST /v1/client/banks
```

### Request body

```json
{
  "type": "openapi",
  "bankShortName": "MBB",
  "accountNumber": "24550721",
  "accName": "PHAM THANH DANH",
  "accMobile": "0858838502",
  "cccd": "012345678901"
}
```

### Tài khoản ngân hàng doanh nghiệp

Với tài khoản doanh nghiệp, gửi thêm `accountType: "BUSINESS"`.

Tài khoản doanh nghiệp ACB Onebiz cần thêm `username` internet banking:

```json
{
  "type": "openapi",
  "bankShortName": "ACB",
  "accountNumber": "24550721",
  "accName": "PHAM THANH DANH",
  "accMobile": "0858838502",
  "accountType": "BUSINESS",
  "username": "internet_banking_user"
}
```

Tài khoản doanh nghiệp MB Bank cần truyền MST (Tax code) vào `cccd`:

```json
{
  "type": "openapi",
  "bankShortName": "MBB",
  "accountNumber": "24550721",
  "accName": "PHAM THANH DANH",
  "accMobile": "0858838502",
  "cccd": "012345678901",
  "accountType": "BUSINESS"
}
```

### Các field quan trọng

- `type`: `openapi`
- `bankShortName`: một trong `BIDV`, `ACB`, `MBB`, `OCB`, `ICB`, `VCB`
- `accountNumber`: số tài khoản ngân hàng
- `accName`: tên chủ tài khoản
- `accMobile`: số điện thoại dùng để xác thực
- `cccd`: bắt buộc với `BIDV` và `MBB`
- `merchantId`: bắt buộc với `BIDV`
- `accEmail`: bắt buộc với `BIDV`
- `accountType`: gửi `BUSINESS` với các tài khoản ngân hàng doanh nghiệp được hỗ trợ
- `username`: bắt buộc với `ICB`, `VCB`, hoặc `ACB` khi `accountType` là `BUSINESS`
- `password`: bắt buộc với `ICB` và `VCB`

Với `OCB`, chỉ cần các field cơ bản: `type`, `bankShortName`, `accountNumber`, `accName`, và `accMobile`.

### Response

ApiPay trả về trực tiếp kết quả từ luồng kết nối ngân hàng. Một số ngân hàng sẽ yêu cầu OTP, khi đó response thường báo cần xác thực thêm và hệ thống tạo bank record ở trạng thái `PENDING`.

## 2. Xác thực OTP khi kết nối

```bash
POST /v1/client/banks/confirm-otp
```

### Request body

```json
{
  "bankShortName": "MBB",
  "accountNumber": "24550721",
  "accountName": "PHAM THANH DANH",
  "otp": "123456",
  "type": "SMS"
}
```

### Ghi chú

- Dùng endpoint này khi bước kết nối trả về yêu cầu OTP
- `merchantId` có thể cần cho một số trường hợp như `BIDV`
- Khi xác thực thành công, bank record sẽ được chuyển từ `PENDING` sang `ACTIVE`

## 3. Lấy danh sách tài khoản ngân hàng đã liên kết

```bash
GET /v1/client/banks
```

### Response

```json
{
  "status": true,
  "message": [
    {
      "id": 12,
      "publicId": "bnk_abc123",
      "bankName": "MB Bank",
      "bankShortName": "MBB",
      "accountNumber": "24550721",
      "accountName": "PHAM THANH DANH",
      "vaNumber": "DANH001",
      "status": "ACTIVE",
      "createdAt": "2026-04-25T10:00:00.000Z"
    }
  ]
}
```

### Trạng thái tài khoản

- `ACTIVE`: đang hoạt động
- `INACTIVE`: đã tắt
- `PENDING`: đang chờ xác thực OTP hoặc hoàn tất liên kết

## 4. Lấy chi tiết một tài khoản ngân hàng

```bash
GET /v1/client/banks/:publicId
```

### Response thành công

```json
{
  "status": true,
  "message": {
    "publicId": "bnk_abc123",
    "bankShortName": "MBB",
    "accountNumber": "24550721",
    "accountName": "PHAM THANH DANH"
  }
}
```

### Nếu không tìm thấy

```json
{
  "status": false,
  "message": null
}
```

## 5. Lấy thống kê ngân hàng

```bash
GET /v1/client/banks/summary
```

### Response

```json
{
  "total": 3,
  "active": 2,
  "inactive": 1,
  "pending": 0
}
```

## 6. Bật hoặc tắt trạng thái ngân hàng

```bash
PATCH /v1/client/banks/:id/status
```

Trong route này, `:id` là `publicId` của bank account.

### Ghi chú

- Chỉ dùng được với tài khoản đã liên kết đầy đủ
- Nếu tài khoản chưa hoàn tất kích hoạt, API sẽ trả lỗi

## 7. Ngắt kết nối tài khoản ngân hàng

```bash
DELETE /v1/client/banks/:id
```

Trong route này, `:id` là `publicId` của bank account.

### Ghi chú

- Một số ngân hàng có thể yêu cầu OTP khi xóa
- Nếu cần OTP, API sẽ trả về kết quả yêu cầu xác thực thay vì xóa ngay

## 8. Xác thực OTP khi ngắt kết nối

```bash
POST /v1/client/banks/:id/confirm-delete
```

### Request body

```json
{
  "otp": "123456"
}
```

## 9. Xóa một ngân hàng chưa xác thực

```bash
POST /v1/client/banks/remove-unconfirmed
```

### Request body

```json
{
  "bankShortName": "MBB",
  "accountNumber": "24550721"
}
```

Endpoint này dùng để dọn record `PENDING` hoặc record chưa hoàn tất xác thực.
