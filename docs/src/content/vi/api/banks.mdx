# Quản lý ngân hàng

Kết nối tài khoản ngân hàng và lấy `publicId` để tạo yêu cầu thanh toán. Mọi endpoint nằm dưới `/v1/client/banks` và cần [xác thực](/vi/api/authentication).

Mọi response được bọc trong `{"data": ..., "statusCode": 200, "timestamp": "..."}`; danh sách nằm ở `data.message`, phân trang ở `data.pagination`.

## Lấy danh sách ngân hàng hỗ trợ

```bash
GET /v1/client/banks/available
```

Trả về các ngân hàng đang nhận liên kết mới, kèm loại tài khoản và thông tin cần nhập cho từng ngân hàng.

```json
{
  "data": {
    "status": true,
    "message": [
      {
        "bankCode": "MBB",
        "bankName": "Ngân hàng TMCP Quân đội",
        "bankBin": "970422",
        "shortName": "MB Bank",
        "logoUrl": "https://...",
        "accountTypes": [
          {"type": "personal-account", "manualActivation": false, "generatesVa": true},
          {"type": "business-account", "manualActivation": false, "generatesVa": true}
        ],
        "requiresIdentity": true,
        "noTransferContent": false,
        "availability": "available"
      }
    ]
  },
  "statusCode": 200,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```

| Trường | Kiểu | Mô tả |
| ------ | ---- | ----- |
| `bankBin` | string | Mã BIN, dùng khi kết nối tài khoản |
| `accountTypes[].type` | string | Loại tài khoản ngân hàng hỗ trợ |
| `accountTypes[].manualActivation` | boolean | `true` nếu loại tài khoản này cần ApiPay kích hoạt thủ công |
| `accountTypes[].generatesVa` | boolean | `true` nếu ApiPay cấp tài khoản ảo (VA) thay vì dùng số tài khoản gốc |
| `requiresIdentity` | boolean | `true` nếu phải gửi `identity` khi kết nối |
| `noTransferContent` | boolean | `true` nếu giao dịch từ ngân hàng này không kèm nội dung chuyển khoản |

## Kết nối tài khoản ngân hàng

```bash
POST /v1/client/banks
```

| Tham số | Kiểu | Bắt buộc | Mô tả |
| ------- | ---- | -------- | ----- |
| `bankBin` | string | Có | Mã BIN lấy từ danh sách ngân hàng hỗ trợ |
| `bankName` | string | Có | Tên ngân hàng để hiển thị |
| `accountType` | string | Có | `personal-account`, `business-account` hoặc `business-household-account` |
| `accountNumber` | string | Có | Số tài khoản ngân hàng |
| `accountName` | string | Có | Tên chủ tài khoản, viết hoa không dấu |
| `mobile` | string | Có | Số điện thoại đăng ký với ngân hàng |
| `identity` | string | Theo ngân hàng | Số CCCD hoặc mã số thuế. Bắt buộc khi `requiresIdentity` là `true` |
| `acbUserId` | string | Theo ngân hàng | Tên đăng nhập ACB OneBiz, bắt buộc với tài khoản doanh nghiệp và hộ kinh doanh ACB |
| `nickname` | string | Không | Tên gợi nhớ, chỉ hiển thị trong dashboard (tối đa 50 ký tự) |

```bash
curl -X POST https://app.apipay.vn/v1/client/banks \
  -H "Authorization: Bearer <Auth>" \
  -H "Content-Type: application/json" \
  -d '{
    "bankBin": "970422",
    "bankName": "MB Bank",
    "accountType": "personal-account",
    "accountNumber": "0123456789",
    "accountName": "NGUYEN VAN A",
    "mobile": "0901234567",
    "identity": "001234567890",
    "nickname": "Shop online"
  }'
```

```json
{
  "data": {
    "status": true,
    "OTP": 1,
    "message": "Vui lòng nhập mã OTP để hoàn tất liên kết tài khoản ngân hàng",
    "bank": {
      "publicId": "bnk_abc123",
      "vaNumber": null,
      "status": "PENDING"
    }
  },
  "statusCode": 201,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```

Bước tiếp theo tùy theo response:

| Response | Ý nghĩa |
| -------- | ------- |
| `OTP: 1` | Ngân hàng đã gửi OTP. Gọi [Xác nhận OTP](#xác-nhận-otp). |
| `OTP: 0`, `bank.status: "ACTIVE"` | Tài khoản đã hoạt động. |
| `activationRequested: true` | Tài khoản ở trạng thái `PENDING`. ApiPay sẽ liên hệ bạn để hoàn tất kích hoạt. |
| `requiresAuthorize: true` | Mở `authorizeLink` và xác nhận liên kết trên ứng dụng ngân hàng. |

## Xác nhận OTP

```bash
POST /v1/client/banks/confirm-otp
```

| Tham số | Kiểu | Bắt buộc | Mô tả |
| ------- | ---- | -------- | ----- |
| `bankBin` | string | Có | Mã BIN đã dùng khi kết nối |
| `accountNumber` | string | Có | Số tài khoản đã dùng khi kết nối |
| `otpNumber` | string | Có | Mã OTP ngân hàng gửi |

```bash
curl -X POST https://app.apipay.vn/v1/client/banks/confirm-otp \
  -H "Authorization: Bearer <Auth>" \
  -H "Content-Type: application/json" \
  -d '{"bankBin": "970422", "accountNumber": "0123456789", "otpNumber": "123456"}'
```

```json
{
  "data": {
    "status": true,
    "message": "Xác nhận ngân hàng thành công"
  },
  "statusCode": 201,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```

## Lấy danh sách tài khoản đã kết nối

```bash
GET /v1/client/banks
```

| Tham số | Kiểu | Bắt buộc | Mô tả |
| ------- | ---- | -------- | ----- |
| `page` | number | Không | Trang, mặc định `1` |
| `limit` | number | Không | Số mục mỗi trang, mặc định `20`, tối đa `50` |
| `search` | string | Không | Tìm theo số tài khoản, tên chủ tài khoản, tên gợi nhớ, số VA hoặc ngân hàng |
| `status` | string | Không | `ACTIVE`, `INACTIVE` hoặc `PENDING` |

```bash
curl "https://app.apipay.vn/v1/client/banks?status=ACTIVE" \
  -H "Authorization: Bearer <Auth>"
```

```json
{
  "data": {
    "status": true,
    "message": [
      {
        "publicId": "bnk_abc123",
        "bankName": "MB Bank",
        "bankShortName": "MB",
        "accountNumber": "0123456789",
        "accountName": "NGUYEN VAN A",
        "nickname": "Shop online",
        "vaNumber": "VA001",
        "status": "ACTIVE",
        "manualActivationPending": false,
        "createdAt": "2026-04-25T10:00:00.000Z"
      }
    ],
    "pagination": {"page": 1, "limit": 20, "total": 1, "totalPages": 1}
  },
  "statusCode": 200,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```

| Trường | Kiểu | Mô tả |
| ------ | ---- | ----- |
| `publicId` | string | Mã tài khoản, dùng làm `bankPublicId` khi tạo yêu cầu thanh toán |
| `vaNumber` | string \| null | Số tài khoản ảo, nếu có |
| `status` | string | `ACTIVE` đang hoạt động, `INACTIVE` đã tắt, `PENDING` chờ OTP hoặc kích hoạt |
| `manualActivationPending` | boolean | `true` khi ApiPay đang xử lý kích hoạt thủ công |

## Lấy chi tiết tài khoản

```bash
GET /v1/client/banks/:publicId
```

`data.message` có cùng cấu trúc với một phần tử trong danh sách. Nếu không tìm thấy, API vẫn trả `200`:

```json
{
  "data": {
    "status": false,
    "message": null
  },
  "statusCode": 200,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```

## Thống kê tài khoản

```bash
GET /v1/client/banks/summary
```

```json
{
  "data": {
    "total": 3,
    "active": 2,
    "inactive": 1,
    "pending": 0
  },
  "statusCode": 200,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```

## Bật hoặc tắt tài khoản

```bash
PATCH /v1/client/banks/:publicId/status
```

Chuyển tài khoản giữa `ACTIVE` và `INACTIVE`. Không áp dụng cho tài khoản `PENDING`. Nếu bạn đã bật passkey hoặc ứng dụng xác thực cho tài khoản ApiPay, API trả `403`; hãy bật hoặc tắt ngân hàng trong dashboard.

```json
{
  "data": {
    "status": true,
    "message": "Cập nhật trạng thái ngân hàng thành công"
  },
  "statusCode": 200,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```

## Đổi tên gợi nhớ

```bash
PATCH /v1/client/banks/:publicId
```

| Tham số | Kiểu | Bắt buộc | Mô tả |
| ------- | ---- | -------- | ----- |
| `nickname` | string | Không | Tên gợi nhớ, tối đa 50 ký tự. Gửi chuỗi rỗng để xóa |

Tên gợi nhớ chỉ hiển thị trong dashboard, khách hàng không thấy. Response trả về tài khoản đã cập nhật trong `data.bank`.

## Ngắt kết nối tài khoản

```bash
DELETE /v1/client/banks/:publicId
```

Tài khoản đang chờ kích hoạt không thể ngắt kết nối.

```json
{
  "data": {
    "status": true,
    "message": "Xóa tài khoản ngân hàng thành công"
  },
  "statusCode": 200,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```
