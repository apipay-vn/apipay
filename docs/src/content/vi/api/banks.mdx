# Quản lý ngân hàng

Dùng API quản lý ngân hàng để lấy danh sách ngân hàng hỗ trợ, kết nối tài khoản, hoàn tất xác thực và quản lý các tài khoản đã liên kết.

Base route:

```bash
/v2/client/banks
```

## Ngân hàng hỗ trợ

| Ngân hàng  | Mã ngắn    | BIN      | Loại tài khoản                       |
| ---------- | ---------- | -------- | ------------------------------------ |
| ACB        | `ACB`      | `970416` | cá nhân, doanh nghiệp, hộ kinh doanh |
| MB Bank    | `MBB`      | `970422` | cá nhân, doanh nghiệp, hộ kinh doanh |
| BIDV       | `BIDV`     | `970418` | cá nhân, doanh nghiệp, hộ kinh doanh |
| OCB        | `OCB`      | `970448` | cá nhân, doanh nghiệp, hộ kinh doanh |
| VietinBank | `ICB`      | `970415` | doanh nghiệp, hộ kinh doanh          |
| VIB        | `VIB`      | `970441` | cá nhân, doanh nghiệp, hộ kinh doanh |
| Sacombank  | `STB`      | `970403` | cá nhân, hộ kinh doanh               |
| VPBank     | `VPB`      | `970432` | cá nhân                              |
| PGBank     | `PGB`      | `970430` | cá nhân, doanh nghiệp, hộ kinh doanh |
| Shinhan    | `SHBVN`    | `970424` | cá nhân, doanh nghiệp                |
| Co-opBank  | `COOPBANK` | `970446` | cá nhân, doanh nghiệp, hộ kinh doanh |

Dùng `GET /v2/client/banks/available` để lấy danh sách ngân hàng hiện có trước khi hiển thị bộ chọn ngân hàng.

## 1. Lấy danh sách ngân hàng khả dụng

```bash
GET /v2/client/banks/available
```

### Response

```json
{
  "status": true,
  "message": [
    {
      "bankCode": "MBB",
      "bankName": "MB Bank",
      "bankBin": "970422",
      "shortName": "MBB",
      "logoUrl": "https://example.com/mbbank.png"
    }
  ]
}
```

## 2. Kết nối tài khoản ngân hàng

```bash
POST /v2/client/banks
```

### Request body

```json
{
  "bankBin": "970422",
  "bankName": "MB Bank",
  "accountType": "personal-account",
  "accountNumber": "24550721",
  "accountName": "PHAM THANH DANH",
  "mobile": "0858838502",
  "identity": "012345678901"
}
```

### Field

| Field           | Kiểu   | Bắt buộc       | Mô tả                                                                    |
| --------------- | ------ | -------------- | ------------------------------------------------------------------------ |
| `bankBin`       | string | Có             | Mã BIN từ endpoint danh sách ngân hàng khả dụng                          |
| `bankName`      | string | Có             | Tên hiển thị của ngân hàng                                               |
| `accountType`   | string | Có             | `personal-account`, `business-account` hoặc `business-household-account` |
| `accountNumber` | string | Có             | Số tài khoản ngân hàng                                                   |
| `accountName`   | string | Có             | Tên chủ tài khoản, viết hoa không dấu                                    |
| `mobile`        | string | Có             | Số điện thoại đăng ký với ngân hàng                                      |
| `identity`      | string | Trừ ACB        | CCCD cho tài khoản cá nhân, hoặc mã số thuế cho tài khoản doanh nghiệp   |
| `acbUserId`     | string | Theo điều kiện | Tên đăng nhập ACB OneBiz cho tài khoản doanh nghiệp và hộ kinh doanh ACB |
| `merchantId`    | string | Theo điều kiện | Mã merchant khi cấu hình kết nối ngân hàng yêu cầu                       |
| `shopId`        | string | Theo điều kiện | Mã cửa hàng khi cấu hình kết nối ngân hàng yêu cầu                       |

Sacombank hỗ trợ `personal-account` và `business-household-account`.
Shinhan hỗ trợ `personal-account` và `business-account`.
VietinBank hỗ trợ `business-account` và `business-household-account` (tài khoản cá nhân không được hỗ trợ).
VPBank chỉ hỗ trợ `personal-account` (tài khoản doanh nghiệp và hộ kinh doanh không được hỗ trợ).

### Response khi cần OTP

```json
{
  "status": true,
  "OTP": 1,
  "type": "openapi",
  "message": "Vui lòng nhập mã OTP để hoàn tất liên kết tài khoản ngân hàng",
  "bank": {
    "publicId": "bnk_abc123",
    "vaNumber": null,
    "status": "PENDING"
  }
}
```

Gửi mã xác thực đến endpoint xác nhận OTP.

### Response khi tài khoản đã hoạt động

```json
{
  "status": true,
  "OTP": 0,
  "type": "openapi",
  "message": "Liên kết tài khoản ngân hàng thành công",
  "bank": {
    "publicId": "bnk_abc123",
    "vaNumber": "DANH001",
    "status": "ACTIVE"
  }
}
```

### Response khi cần kích hoạt thủ công

```json
{
  "status": true,
  "activationRequested": true,
  "OTP": 0,
  "type": "openapi",
  "message": "Tài khoản đã được kết nối và đang chờ xác minh. Quá trình kích hoạt có thể mất đến 24 giờ.",
  "bank": {
    "publicId": "bnk_abc123",
    "vaNumber": null,
    "status": "PENDING"
  }
}
```

Kích hoạt thủ công áp dụng cho:

- Tài khoản doanh nghiệp hoặc hộ kinh doanh của MB Bank, OCB, VIB
- Tài khoản doanh nghiệp của BIDV và VietinBank

ApiPay sẽ liên hệ chủ tài khoản để hoàn tất kích hoạt.

## 3. Xác nhận OTP

```bash
POST /v2/client/banks/confirm-otp
```

### Request body

```json
{
  "bankBin": "970422",
  "accountNumber": "24550721",
  "otpNumber": "123456"
}
```

### Response

```json
{
  "status": true,
  "message": "Xác nhận ngân hàng thành công"
}
```

## 4. Lấy danh sách tài khoản ngân hàng đã liên kết

```bash
GET /v2/client/banks
```

### Response

```json
{
  "status": true,
  "message": [
    {
      "id": 12,
      "publicId": "bnk_abc123",
      "bankName": "MB Bank",
      "bankShortName": "MBB",
      "accountNumber": "24550721",
      "accountName": "PHAM THANH DANH",
      "vaNumber": "DANH001",
      "status": "ACTIVE",
      "manualActivationPending": false,
      "createdAt": "2026-04-25T10:00:00.000Z"
    }
  ]
}
```

### Trạng thái tài khoản

- `ACTIVE`: đang hoạt động và có thể sử dụng
- `INACTIVE`: đã tắt
- `PENDING`: đang chờ OTP hoặc kích hoạt thủ công

`manualActivationPending` là `true` trong thời gian ApiPay xử lý yêu cầu kích hoạt thủ công.

## 5. Lấy chi tiết tài khoản ngân hàng

```bash
GET /v2/client/banks/:publicId
```

### Response thành công

```json
{
  "status": true,
  "message": {
    "publicId": "bnk_abc123",
    "bankName": "MB Bank",
    "bankShortName": "MBB",
    "accountNumber": "24550721",
    "accountName": "PHAM THANH DANH",
    "vaNumber": "DANH001",
    "status": "ACTIVE",
    "manualActivationPending": false
  }
}
```

### Response khi không tìm thấy

```json
{
  "status": false,
  "message": null
}
```

## 6. Lấy thống kê ngân hàng

```bash
GET /v2/client/banks/summary
```

### Response

```json
{
  "total": 3,
  "active": 2,
  "inactive": 1,
  "pending": 0
}
```

## 7. Bật hoặc tắt tài khoản ngân hàng

```bash
PATCH /v2/client/banks/:publicId/status
```

Endpoint chuyển trạng thái tài khoản giữa `ACTIVE` và `INACTIVE`.

### Response

```json
{
  "status": true,
  "message": "Cập nhật trạng thái ngân hàng thành công",
  "newStatus": 1
}
```

`newStatus` là `1` khi tài khoản hoạt động và `0` khi đã tắt. Không thể đổi trạng thái tài khoản đang chờ kích hoạt.

## 8. Ngắt kết nối tài khoản ngân hàng

```bash
DELETE /v2/client/banks/:publicId
```

Tài khoản được ngắt kết nối ngay, trừ khi ngân hàng yêu cầu xác nhận OTP.

### Response khi cần OTP

```json
{
  "status": true,
  "OTP": 1,
  "type": "openapi",
  "message": "Vui lòng nhập mã OTP để xác nhận xóa ngân hàng"
}
```

Không thể ngắt kết nối tài khoản đang chờ kích hoạt thủ công cho đến khi ApiPay xử lý xong yêu cầu.

## 9. Xác nhận ngắt kết nối ngân hàng

```bash
POST /v2/client/banks/:publicId/confirm-delete
```

### Request body

```json
{
  "otp": "123456"
}
```

### Response

```json
{
  "status": true,
  "message": "Xóa tài khoản ngân hàng thành công"
}
```
