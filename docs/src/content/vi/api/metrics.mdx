# Metrics API

API dùng để lấy số liệu thống kê và phân tích giao dịch.

## Tổng quan

Lấy tổng quan giao dịch, gồm tổng tiền, số lượng và giá trị trung bình.

```bash
GET /v1/client/metrics/overview
```

### Headers

| Header | Mô tả |
|--------|--------|
| `Authorization` | `Bearer <Auth>` |

### Query Parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---------|------|----------|--------|
| `period` | string | — | Khoảng thời gian: `today`, `this_week`, `last_week`, `this_month`, `last_month`, `last_3_months`, `last_6_months`, `this_year`, `custom` |
| `dateFrom` | string | — | Ngày bắt đầu (ISO 8601) |
| `dateTo` | string | — | Ngày kết thúc (ISO 8601) |
| `search` | string | — | Tìm theo mã tham chiếu, nội dung, số tài khoản, tên ngân hàng, mã ngân hàng hoặc số VA |

### Response

```json
{
  "data": {
    "totalIn": 5000000,
    "totalOut": 0,
    "totalTransactions": 50,
    "averageAmount": 115000,
    "successRate": 90,
    "byBank": [
      {
        "bankName": "MB",
        "accountNumber": "0123456789",
        "totalIn": 3000000,
        "countIn": 30,
        "totalOut": 0,
        "countOut": 0
      }
    ]
  }
}
```

## Time Series

Lấy dữ liệu theo thời gian để vẽ biểu đồ.

```bash
GET /v1/client/metrics/time-series
```

### Query Parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---------|------|----------|--------|
| `period` | string | — | Khoảng thời gian |
| `dateFrom` | string | — | Ngày bắt đầu (ISO 8601) |
| `dateTo` | string | — | Ngày kết thúc (ISO 8601) |
| `granularity` | string | — | Độ chi tiết: `daily`, `weekly`, `monthly` |

### Response

```json
{
  "data": [
    {
      "date": "2026-03-01",
      "totalIn": 1000000,
      "totalOut": 0,
      "count": 10
    },
    {
      "date": "2026-03-02",
      "totalIn": 1500000,
      "totalOut": 0,
      "count": 15
    }
  ]
}
```

## Giao dịch trong ngày

Lấy giao dịch theo từng giờ trong một ngày theo giờ Việt Nam.

```bash
GET /v1/client/metrics/hourly-transactions
```

### Query Parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---------|------|----------|--------|
| `date` | string | — | Ngày dạng `YYYY-MM-DD`, hiểu theo múi giờ `Asia/Ho_Chi_Minh`. Mặc định là hôm nay tại Việt Nam. |
| `status` | string[] | — | Lọc theo trạng thái giao dịch: `SUCCESS`, `FAILED`, `PENDING` |
| `bankAccountId` | number[] | — | Lọc theo một hoặc nhiều ID tài khoản ngân hàng |

### Response

```json
{
  "data": [
    {
      "hour": 0,
      "label": "00:00",
      "SUCCESS_amount": 2500000,
      "SUCCESS_count": 5,
      "FAILED_amount": 0,
      "FAILED_count": 0,
      "PENDING_amount": 100000,
      "PENDING_count": 1,
      "total_amount": 2600000,
      "total_count": 6
    },
    {
      "hour": 1,
      "label": "01:00",
      "SUCCESS_amount": 0,
      "SUCCESS_count": 0,
      "FAILED_amount": 0,
      "FAILED_count": 0,
      "PENDING_amount": 0,
      "PENDING_count": 0,
      "total_amount": 0,
      "total_count": 0
    }
  ]
}
```

## Phân bố theo ngân hàng

Lấy tỷ trọng giao dịch theo ngân hàng.

## Danh sách giao dịch

Lấy danh sách giao dịch, có phân trang.

```bash
GET /v1/client/metrics/transactions
```

### Query Parameters

| Tham số | Kiểu | Bắt buộc | Mô tả |
|---------|------|----------|--------|
| `period` | string | — | Khoảng thời gian |
| `dateFrom` | string | — | Ngày bắt đầu (ISO 8601) |
| `dateTo` | string | — | Ngày kết thúc (ISO 8601) |
| `search` | string | — | Tìm theo mã tham chiếu, nội dung, số tài khoản, tên ngân hàng, mã ngân hàng hoặc số VA |
| `page` | number | — | Số trang (mặc định: 1) |
| `limit` | number | — | Số item trên mỗi trang (mặc định: 20, tối đa: 100) |
| `sortBy` | string | — | Sắp xếp theo: `transactionDate`, `amount`, `createdAt` |
| `sortOrder` | string | — | Thứ tự sắp xếp: `asc`, `desc` |

### Response

```json
{
  "data": {
    "data": [
      {
        "id": "txn_abc123",
        "amount": "100000",
        "type": "IN",
        "content": "ORDER-001",
        "referenceCode": "TX123456789",
        "transactionDate": "2026-03-06T10:05:00Z",
        "status": "SUCCESS",
        "createdAt": "2026-03-06T10:00:00Z",
        "bankAccount": {
          "bankShortName": "MB",
          "bankName": "MB Bank",
          "accountNumber": "0123456789",
          "accountName": "NGUYEN VAN A"
        }
      }
    ],
    "meta": {
      "total": 50,
      "page": 1,
      "limit": 20,
      "totalPages": 3
    }
  }
}
```
