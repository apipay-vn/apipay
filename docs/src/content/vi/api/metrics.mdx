# Metrics API

Tra cứu giao dịch đã nhận và số liệu tổng quan. Mọi request cần header `Authorization: Bearer <Auth>` (xem [Xác thực API](/vi/api/authentication)).

## Bộ lọc thời gian

Các endpoint dưới đây nhận cùng bộ lọc thời gian:

| Tham số    | Kiểu   | Bắt buộc | Mô tả                                                                                                           |
| ---------- | ------ | -------- | --------------------------------------------------------------------------------------------------------------- |
| `period`   | string | Không    | `today`, `yesterday`, `this_week`, `last_week`, `this_month`, `last_month`, `last_3_months`, `last_6_months`, `this_year`, `custom` |
| `dateFrom` | string | Không    | Từ ngày, dạng `YYYY-MM-DD` (giờ Việt Nam). Dùng với `period=custom`                                              |
| `dateTo`   | string | Không    | Đến hết ngày, dạng `YYYY-MM-DD` (giờ Việt Nam). Dùng với `period=custom`                                         |

## Danh sách giao dịch

```bash
GET /v1/client/metrics/transactions
```

Ngoài bộ lọc thời gian:

| Tham số         | Kiểu     | Bắt buộc | Mô tả                                                        |
| --------------- | -------- | -------- | ------------------------------------------------------------ |
| `search`        | string   | Không    | Tìm theo mã tham chiếu, nội dung, số tài khoản hoặc số VA    |
| `bankPublicId`  | string[] | Không    | Lọc theo tài khoản ngân hàng. Truyền nhiều lần để lọc nhiều  |
| `accountNumber` | string   | Không    | Lọc theo số tài khoản hoặc số VA                             |
| `sortBy`        | string   | Không    | `transactionDate` (mặc định), `amount` hoặc `createdAt`      |
| `sortOrder`     | string   | Không    | `desc` (mặc định) hoặc `asc`                                 |
| `page`          | number   | Không    | Mặc định `1`                                                 |
| `limit`         | number   | Không    | Mặc định `20`, tối đa `100`                                  |

```bash
curl -G https://app.apipay.vn/v1/client/metrics/transactions \
  -H "Authorization: Bearer <Auth>" \
  --data-urlencode "period=today" \
  --data-urlencode "search=ORDER-12345"
```

## Chi tiết giao dịch

`id` là `transactionId` trong [webhook](/vi/api/webhooks). Response giống một phần tử trong danh sách giao dịch.

```bash
GET /v1/client/metrics/transactions/:id
```

## Tổng quan

Tổng tiền vào, số giao dịch và giá trị trung bình trong khoảng thời gian đã chọn.

```bash
GET /v1/client/metrics/overview
```

```bash
curl -G https://app.apipay.vn/v1/client/metrics/overview \
  -H "Authorization: Bearer <Auth>" \
  --data-urlencode "period=this_month"
```

```json
{
  "data": {
    "totalIn": 5000000,
    "totalTransactions": 50,
    "averageAmount": 100000,
    "comparison": null
  },
  "statusCode": 200,
  "timestamp": "2026-08-12T10:35:00.000Z"
}
```

| Trường              | Kiểu           | Mô tả                                                    |
| ------------------- | -------------- | -------------------------------------------------------- |
| `totalIn`           | number         | Tổng tiền vào (VND)                                      |
| `totalTransactions` | number         | Số giao dịch                                             |
| `averageAmount`     | number         | Giá trị trung bình mỗi giao dịch (VND)                   |
| `comparison`        | object \| null | So sánh với kỳ trước. Chỉ có khi `period=this_month`     |
