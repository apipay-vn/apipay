# Xác thực API

Mọi endpoint `/v1/client/*` cần header `Authorization` tạo từ khóa API của bạn:

```
Authorization: Bearer base64(accessKey:secretKey)
```

## Lấy khóa API

Đăng nhập [my.apipay.vn](https://my.apipay.vn), vào **Tích hợp → Web App → API Keys** và tạo khóa mới. Bạn nhận được:

- `accessKey`: định danh khóa API.
- `secretKey`: khóa bí mật. Chỉ dùng ở phía server, không đưa vào mã chạy trên trình duyệt hoặc ứng dụng di động.

## Khóa thử nghiệm và khóa thật

| Loại | Nhận biết | Mục đích |
| ---- | --------- | -------- |
| Thử nghiệm | `accessKey` bắt đầu bằng `ak_test_` | [Sandbox](/vi/sandbox), không có tiền thật |
| Thật | Không có tiền tố | Giao dịch thật |

Cả hai dùng chung URL `https://app.apipay.vn`. Gọi bằng khóa thử nghiệm thì request chạy trong sandbox.

## Ví dụ

<CodeTabs>
```javascript
const ACCESS_KEY = "your_access_key";
const SECRET_KEY = "your_secret_key";

async function main() {
  const auth = Buffer.from(`${ACCESS_KEY}:${SECRET_KEY}`).toString("base64");

  const response = await fetch("https://app.apipay.vn/v1/client/payment-requests", {
    method: "POST",
    headers: {
      Authorization: `Bearer ${auth}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({bankPublicId: "bnk_abc123", amount: "100000", content: "ORDER-001"}),
  });
  console.log(await response.json());
}

main();
```

```python
import base64
import requests

ACCESS_KEY = 'your_access_key'
SECRET_KEY = 'your_secret_key'

auth = base64.b64encode(f'{ACCESS_KEY}:{SECRET_KEY}'.encode()).decode()

response = requests.post(
  'https://app.apipay.vn/v1/client/payment-requests',
  json={'bankPublicId': 'bnk_abc123', 'amount': '100000', 'content': 'ORDER-001'},
  headers={'Authorization': f'Bearer {auth}'},
)
print(response.json())
```

```php
<?php

use Illuminate\Support\Facades\Http;

$accessKey = 'your_access_key';
$secretKey = 'your_secret_key';

$auth = base64_encode("{$accessKey}:{$secretKey}");

$response = Http::withToken($auth)->post('https://app.apipay.vn/v1/client/payment-requests', [
  'bankPublicId' => 'bnk_abc123',
  'amount' => '100000',
  'content' => 'ORDER-001',
]);
```

```bash
AUTH=$(echo -n "your_access_key:your_secret_key" | base64 | tr -d "\n")

curl -X POST https://app.apipay.vn/v1/client/payment-requests \
  -H "Authorization: Bearer $AUTH" \
  -H "Content-Type: application/json" \
  -d '{"bankPublicId": "bnk_abc123", "amount": "100000", "content": "ORDER-001"}'
```

## Lỗi xác thực

Thiếu header, sai định dạng hoặc khóa không hợp lệ đều trả `401`:

```json
{
  "statusCode": 401,
  "timestamp": "2026-08-12T14:27:45.000Z",
  "path": "/v1/client/payment-requests",
  "method": "POST",
  "message": "API Key không hợp lệ"
}
```
