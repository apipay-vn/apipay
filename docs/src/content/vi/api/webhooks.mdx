# Webhooks

Webhook cho phép bạn nhận thông báo theo thời gian thực khi có sự kiện thanh toán.

## Đăng ký Webhook

Cấu hình webhook URL trong dashboard tại **Cài đặt → Webhooks**, hoặc tạo bằng API.

```bash
POST /v1/client/webhooks
```

### Request Body

| Tham số        | Kiểu   | Bắt buộc | Mô tả                                      |
| -------------- | ------ | -------- | ------------------------------------------ |
| `webhookUrl`   | string | **✓ Có** | HTTPS URL để nhận webhook                  |
| `bankPublicId` | string | **✓ Có** | Public ID của tài khoản ngân hàng          |
| `type`         | string | **✓ Có** | Loại giao dịch: `IN`, `OUT`, hoặc `ALL`    |

### Response

```json
{
	"data": {
		"message": "Tạo webhook thành công",
		"id": "wh_abc123",
		"bankPublicId": "bnk_abc123",
		"webhookUrl": "https://your-domain.com/webhooks/apipay",
		"type": "IN",
		"secret": "a1b2c3d4..."
	}
}
```

Hãy lưu `secret`; khoá này được dùng để xác minh `ApiPay-Signature`.

## Quản lý Webhooks

| Endpoint | Mô tả |
| -------- | ----- |
| `GET /v1/client/webhooks` | Danh sách webhook (`page`, `limit`) |
| `PATCH /v1/client/webhooks/:id` | Cập nhật `webhookUrl` hoặc `type` |
| `PATCH /v1/client/webhooks/:id/toggle` | Bật hoặc tắt webhook |
| `DELETE /v1/client/webhooks/:id` | Xoá webhook |
| `GET /v1/client/webhooks/:id/history` | Xem lịch sử gửi (`page`, `limit`) |
| `POST /v1/client/webhooks/history/:historyId/resend` | Gửi lại một lần gửi thất bại |


### Các trường dữ liệu

| Trường                     | Kiểu   | Mô tả                                                 |
| -------------------------- | ------ | ----------------------------------------------------- |
| `event`                    | string | Loại sự kiện: `transaction.in` hoặc `transaction.out` |
| `data.transactionId`       | string | ID giao dịch nội bộ (UUID)                            |
| `data.referenceCode`       | string | Mã tham chiếu giao dịch ngân hàng                     |
| `data.amount`              | number | Số tiền giao dịch (VND)                               |
| `data.type`                | string | Loại giao dịch: `IN` hoặc `OUT`                       |
| `data.content`             | string | Nội dung giao dịch                                    |
| `data.transactionDate`     | string | Thời gian giao dịch (ISO 8601)                        |
| `data.bankAccountPublicId` | string | Public ID của tài khoản ngân hàng                     |
| `data.gateway`             | string | Mã ngân hàng (VD: BIDV, ACB, MBB, OCB)                |
| `data.rawTransactionDate`  | string | Ngày giao dịch gốc từ ngân hàng                       |
| `data.vaNumber`            | string | Số tài khoản ảo (tuỳ chọn)                            |
| `data.accountNumber`       | string | Số tài khoản người gửi/nhận                           |

## Xác thực Webhook

Tất cả webhook requests đều có header `ApiPay-Signature` để xác thực.

### Node.js

```javascript
const crypto = require("crypto");

function verifyWebhookSignature(payload, signature, secretKey) {
	const expectedSignature = crypto
		.createHmac("sha256", secretKey)
		.update(payload)
		.digest("hex");

	return crypto.timingSafeEqual(
		Buffer.from(signature),
		Buffer.from(expectedSignature),
	);
}

// Sử dụng trong Express
app.post("/webhook", (req, res) => {
	const signature = req.headers["apipay-signature"];
	const payload = JSON.stringify(req.body);

	if (!verifyWebhookSignature(payload, signature, process.env.WEBHOOK_SECRET)) {
		return res.status(401).json({error: "Invalid signature"});
	}

	// Xử lý webhook
	const {event, data} = req.body;

	if (event === "transaction.in") {
		console.log("Tiền vào:", data.amount);
		console.log("Mã tham chiếu:", data.referenceCode);
		console.log("Nội dung:", data.content);
		// Cập nhật đơn hàng trong database của bạn
	} else if (event === "transaction.out") {
		console.log("Tiền ra:", data.amount);
		console.log("Mã tham chiếu:", data.referenceCode);
	}

	res.status(200).json({received: true});
});
```

### Python

```python
import hmac
import hashlib

def verify_webhook_signature(payload: str, signature: str, secret_key: str) -> bool:
    expected_signature = hmac.new(
        secret_key.encode(),
        payload.encode(),
        hashlib.sha256
    ).hexdigest()

    return hmac.compare_digest(signature, expected_signature)

# Sử dụng trong Flask
@app.route('/webhook', methods=['POST'])
def handle_webhook():
    signature = request.headers.get('ApiPay-Signature')
    payload = request.get_data(as_text=True)

    if not verify_webhook_signature(payload, signature, WEBHOOK_SECRET):
        return {'error': 'Invalid signature'}, 401

    data = request.get_json()
    event = data.get('event')

    if event == 'transaction.in':
        print(f"Tiền vào: {data['data']['amount']}")
        print(f"Mã tham chiếu: {data['data']['referenceCode']}")
        print(f"Nội dung: {data['data']['content']}")
        # Cập nhật đơn hàng
    elif event == 'transaction.out':
        print(f"Tiền ra: {data['data']['amount']}")
        # Xử lý giao dịch ra

    return {'received': True}, 200
```

## Retry Policy

- Lần 0: Ngay lập tức

Nếu webhook delivery thất bại, hệ thống sẽ retry:

- Lần 1: Sau 5 giây
- Lần 2: Sau 20 giây
- Lần 3: Sau 1 phút

Sau 3 lần retry thất bại, webhook sẽ bị vô hiệu hoá.

## Testing Webhooks

Sử dụng [Webhook.site](https://webhook.site) để test webhook trong quá trình development:

1. Tạo URL test tại webhook.site
2. Cấu hình webhook URL trong dashboard
3. Tạo payment và hoàn thành thanh toán
4. Xem request trên webhook.site

## Best Practices

1. **Luôn verify signature** trước khi xử lý webhook
2. **Response nhanh** - Trả 200 ngay lập tức, xử lý async
3. **Idempotent** - Xử lý duplicate events không gây lỗi
4. **Log events** - Ghi log để debug nếu cần
