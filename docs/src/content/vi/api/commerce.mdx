# Commerce API

Tạo sản phẩm và mức giá một lần, rồi tạo yêu cầu thanh toán bằng `priceId` thay cho `amount`. Mọi endpoint cần [xác thực](/vi/api/authentication). Có thể gọi thử trong [Tài liệu tương tác](/vi/api-reference).

Mọi response được bọc trong `{"data": ..., "statusCode": 200, "timestamp": "..."}`. Với Commerce, kết quả nằm ở `data.data`; danh sách có thêm `data.pagination`.

## Endpoint

Các path dưới đây nằm sau `/v1/client/commerce`, trừ hai endpoint ảnh có path đầy đủ.

| Method | Path | Mô tả |
| ------ | ---- | ----- |
| `POST` | `/products` | Tạo sản phẩm, có thể kèm mức giá mặc định |
| `GET` | `/products` | Danh sách sản phẩm (`active`, `page`, `limit`) |
| `GET` | `/products/:id` | Sản phẩm kèm các mức giá |
| `PATCH` | `/products/:id` | Cập nhật sản phẩm |
| `POST` | `/prices` | Tạo mức giá |
| `GET` | `/prices` | Danh sách mức giá (`productId`, `lookupKey`, `active`, `page`, `limit`) |
| `GET` | `/prices/:id` | Một mức giá |
| `PATCH` | `/prices/:id` | Cập nhật mức giá |
| `DELETE` | `/prices/:id` | Xóa mức giá chưa từng được dùng |
| `GET` | `/invoices` | Danh sách biên lai (`search`, `page`, `limit`) |
| `GET` | `/invoices/:id` | Chi tiết biên lai |
| `GET` | `/invoices/:id/pdf` | Tải PDF biên lai |
| `PATCH` | `/invoices/:id` | Cập nhật thông tin người mua |
| `POST` | `/invoices/send` | Gửi yêu cầu thanh toán qua email |
| `GET` | `/customers` | Danh sách khách hàng (`search`, `page`, `limit`) |
| `POST` | `/customers` | Tạo khách hàng |
| `GET` | `/customers/:id` | Chi tiết khách hàng |
| `PATCH` | `/customers/:id` | Cập nhật khách hàng |
| `DELETE` | `/customers/:id` | Xóa khách hàng |
| `POST` | `/v1/client/media` | Tải ảnh sản phẩm |
| `DELETE` | `/v1/client/media/:id` | Xóa ảnh |

## Tạo sản phẩm

```bash
POST /v1/client/commerce/products
```

| Tham số | Kiểu | Bắt buộc | Mô tả |
| ------- | ---- | -------- | ----- |
| `name` | string | Có | Tên sản phẩm (tối đa 200 ký tự) |
| `description` | string | Không | Mô tả bằng HTML cơ bản: `p`, `br`, `strong`, `em`, `u`, `s`, `a`, `ul`, `ol`, `li`, `blockquote`, `code`, `pre` (tối đa 10.000 ký tự) |
| `defaultPriceData` | object | Không | Tạo mức giá đầu tiên và đặt làm mặc định |
| `defaultPriceData.unitAmount` | string | Có, nếu gửi `defaultPriceData` | Số tiền VND, số nguyên từ 1 đến 300.000.000 |
| `defaultPriceData.lookupKey` | string | Không | Mã do bạn đặt để tra cứu, ví dụ `pro-monthly` |
| `defaultPriceData.nickname` | string | Không | Tên nội bộ, khách không thấy |

```bash
curl -X POST https://app.apipay.vn/v1/client/commerce/products \
  -H "Authorization: Bearer <Auth>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Gói Pro",
    "description": "<p>Truy cập hằng tháng</p>",
    "defaultPriceData": {
      "unitAmount": "99000",
      "lookupKey": "pro-monthly",
      "nickname": "Giá ra mắt"
    }
  }'
```

```json
{
  "data": {
    "status": true,
    "data": {
      "id": "cml8x1abc0000prod0000000",
      "name": "Gói Pro",
      "description": "<p>Truy cập hằng tháng</p>",
      "active": true,
      "imageId": null,
      "imageUrl": null,
      "defaultPriceId": "cml8x1abc0000price0000000",
      "defaultPrice": {
        "id": "cml8x1abc0000price0000000",
        "productId": "cml8x1abc0000prod0000000",
        "publicId": "plA2B3C4D5E6F7",
        "unitAmount": "99000",
        "currency": "VND",
        "lookupKey": "pro-monthly",
        "nickname": "Giá ra mắt",
        "active": true,
        "paymentLinkUrl": "https://pay.apipay.vn/p/plA2B3C4D5E6F7"
      },
      "activePriceCount": 1
    }
  },
  "statusCode": 201,
  "timestamp": "2026-09-04T10:00:00.000Z"
}
```

Ví dụ lược bỏ `prices`: danh sách mọi mức giá của sản phẩm, cùng cấu trúc với `defaultPrice`.

## Cập nhật sản phẩm

```bash
PATCH /v1/client/commerce/products/:id
```

| Tham số | Kiểu | Bắt buộc | Mô tả |
| ------- | ---- | -------- | ----- |
| `name` | string | Không | Tên sản phẩm |
| `description` | string \| null | Không | Mô tả HTML. Gửi `null` để xóa |
| `active` | boolean | Không | `false` để lưu trữ, `true` để khôi phục |
| `defaultPriceId` | string \| null | Không | Một mức giá đang hoạt động của sản phẩm này. Gửi `null` để bỏ |
| `imageId` | string \| null | Không | `id` ảnh từ `POST /v1/client/media`. Gửi `null` để gỡ |

Sửa sản phẩm không làm thay đổi các yêu cầu thanh toán đã tạo.

## Tải ảnh sản phẩm

```bash
POST /v1/client/media
```

Gửi `multipart/form-data` với `file` (PNG, JPEG hoặc WebP) và `kind=commerce_product`. Dùng `id` trả về làm `imageId` khi cập nhật sản phẩm.

```bash
curl -X POST https://app.apipay.vn/v1/client/media \
  -H "Authorization: Bearer <Auth>" \
  -F "kind=commerce_product" \
  -F "file=@product.png"
```

## Tạo mức giá

```bash
POST /v1/client/commerce/prices
```

| Tham số | Kiểu | Bắt buộc | Mô tả |
| ------- | ---- | -------- | ----- |
| `productId` | string | Có | Sản phẩm chứa mức giá |
| `unitAmount` | string | Có | Số tiền VND, số nguyên từ 1 đến 300.000.000 |
| `lookupKey` | string | Không | Mã tra cứu, không trùng trong tài khoản |
| `nickname` | string | Không | Tên nội bộ |
| `transferLookupKey` | boolean | Không | `true` để lấy `lookupKey` từ mức giá đang giữ mã đó thay vì báo lỗi |

```bash
curl -X POST https://app.apipay.vn/v1/client/commerce/prices \
  -H "Authorization: Bearer <Auth>" \
  -H "Content-Type: application/json" \
  -d '{
    "productId": "cml8x1abc0000prod0000000",
    "unitAmount": "199000",
    "lookupKey": "pro-yearly",
    "nickname": "Theo năm"
  }'
```

Nếu sản phẩm chưa có giá mặc định, mức giá này trở thành mặc định. Tìm lại mức giá theo mã tra cứu:

```bash
curl "https://app.apipay.vn/v1/client/commerce/prices?lookupKey=pro-monthly" \
  -H "Authorization: Bearer <Auth>"
```

## Cập nhật mức giá

```bash
PATCH /v1/client/commerce/prices/:id
```

| Tham số | Kiểu | Bắt buộc | Mô tả |
| ------- | ---- | -------- | ----- |
| `active` | boolean | Không | `false` để lưu trữ, `true` để khôi phục |
| `nickname` | string \| null | Không | Gửi `null` để xóa |
| `lookupKey` | string \| null | Không | Gửi `null` để xóa |
| `transferLookupKey` | boolean | Không | Lấy `lookupKey` từ mức giá đang giữ mã đó |

Không thể sửa `unitAmount`. Muốn đổi giá, tạo mức giá mới rồi lưu trữ mức cũ. Mức giá đã lưu trữ không dùng để tạo yêu cầu thanh toán mới; yêu cầu đã tạo vẫn giữ số tiền cũ.

## Xóa mức giá

```bash
DELETE /v1/client/commerce/prices/:id
```

Chỉ xóa được mức giá chưa từng dùng cho yêu cầu thanh toán nào. Mức giá đã dùng trả `409`; hãy lưu trữ bằng `PATCH`.

---

## Tạo yêu cầu thanh toán từ mức giá

Gửi `priceId` thay cho `amount` (không gửi cả hai). Số tiền lấy từ mức giá; nếu bỏ `title`, ApiPay dùng tên sản phẩm. `customer` không bắt buộc, dùng để điền sẵn thông tin người mua trên biên lai.

```bash
curl -X POST https://app.apipay.vn/v1/client/payment-requests \
  -H "Authorization: Bearer <Auth>" \
  -H "Content-Type: application/json" \
  -d '{
    "bankPublicId": "bnk_abc123",
    "priceId": "cml8x1abc0000price0000000",
    "content": "DONHANG-001",
    "customer": {
      "name": "Nguyễn Văn A",
      "email": "customer@example.com"
    }
  }'
```

Xem [Yêu cầu thanh toán](/vi/api/payment-requests) cho response và [Webhook](/vi/api/webhooks) cho payload khi khách trả.

Mỗi mức giá còn có `paymentLinkUrl`, một link thanh toán dùng lại được. Chia sẻ link này thay vì tạo yêu cầu thanh toán cho từng khách: khách nhập họ tên, email rồi nhận mã QR riêng.

## Biên lai

Khi khách trả qua link hoặc yêu cầu thanh toán tạo từ mức giá, ApiPay tạo biên lai số `CINV-YYYYMM-XXXX` và gửi PDF tới email người mua nếu có (chỉ với giao dịch thật).

<Callout type="warning">
Biên lai ghi nhận thanh toán giữa bạn và khách hàng, **không phải hóa đơn GTGT**.
</Callout>

### Danh sách biên lai

```bash
GET /v1/client/commerce/invoices
```

| Tham số | Kiểu | Bắt buộc | Mô tả |
| ------- | ---- | -------- | ----- |
| `search` | string | Không | Tìm theo số biên lai, tên hoặc email người mua, tên sản phẩm |
| `page` | number | Không | Trang, mặc định `1` |
| `limit` | number | Không | Số mục mỗi trang, mặc định `20`, tối đa `100` |

### Chi tiết và PDF

`GET /invoices/:id` trả về bên bán, bên mua, tổng tiền và `lineItems`. `GET /invoices/:id/pdf` trả về file `application/pdf`.

### Cập nhật thông tin người mua

```bash
PATCH /v1/client/commerce/invoices/:id
```

| Tham số | Kiểu | Bắt buộc | Mô tả |
| ------- | ---- | -------- | ----- |
| `buyerName` | string | Không | Tên người mua |
| `buyerEmail` | string | Không | Email người mua |
| `buyerTaxCode` | string | Không | Mã số thuế |
| `buyerAddress` | string | Không | Địa chỉ |

### Gửi yêu cầu thanh toán qua email

```bash
POST /v1/client/commerce/invoices/send
```

Tạo yêu cầu thanh toán VietQR và gửi link qua email cho khách. Khi khách trả xong, biên lai được tạo và gửi lại cho khách. Gửi quá nhiều trong thời gian ngắn sẽ nhận `429`.

| Tham số | Kiểu | Bắt buộc | Mô tả |
| ------- | ---- | -------- | ----- |
| `priceId` | string | Có | Mức giá đang hoạt động |
| `customerId` | string | Một trong hai | Khách hàng đã có |
| `customer` | object | Một trong hai | Khách hàng mới: `name`, `email` bắt buộc; `taxCode`, `address` không bắt buộc |
| `expiresAt` | string | Không | Hạn thanh toán, định dạng ISO 8601 |

```bash
curl -X POST https://app.apipay.vn/v1/client/commerce/invoices/send \
  -H "Authorization: Bearer <Auth>" \
  -H "Content-Type: application/json" \
  -d '{
    "customerId": "cml8x1abc0000cust000000",
    "priceId": "cml8x1abc0000price0000000"
  }'
```

## Khách hàng

### Tạo khách hàng

```bash
POST /v1/client/commerce/customers
```

| Tham số | Kiểu | Bắt buộc | Mô tả |
| ------- | ---- | -------- | ----- |
| `name` | string | Có | Tên khách hàng (tối đa 200 ký tự) |
| `email` | string | Có | Email, không trùng trong tài khoản (tối đa 200 ký tự) |
| `taxCode` | string | Không | Mã số thuế (tối đa 50 ký tự) |
| `address` | string | Không | Địa chỉ (tối đa 500 ký tự), bắt buộc khi có `taxCode` |

`PATCH /customers/:id` nhận cùng các trường. Đổi `email` sang email của khách hàng khác trả `409`.

### Danh sách và chi tiết

`GET /customers` nhận `search` (tên, email hoặc mã số thuế), `page`, `limit`. `GET /customers/:id` trả thêm các yêu cầu thanh toán và biên lai gần nhất của khách.

### Xóa khách hàng

```bash
DELETE /v1/client/commerce/customers/:id
```

Khách hàng đã có yêu cầu thanh toán hoặc biên lai trả `409`.
