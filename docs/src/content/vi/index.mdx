# Giới thiệu ApiPay

ApiPay giúp bạn nhận thanh toán chuyển khoản ngân hàng qua API. Bạn tạo link thanh toán, khách quét QR hoặc chuyển khoản, ApiPay ghi nhận giao dịch và gửi webhook về hệ thống của bạn.

![Tổng quan tài liệu ApiPay](/apipay-docs.jpg)

## Tính năng chính

- **Tạo liên kết thanh toán** qua QR Code hoặc thông tin chuyển khoản
- **Tự động xác nhận** khi tiền vào tài khoản
- **Loa Thanh Toán miễn phí** - Đọc thông báo tiền về realtime tại quầy thu ngân trên mọi thiết bị
- **Webhook notifications** - Nhận thông báo thanh toán gần như ngay lập tức
- **Nhiều ngân hàng** - Hỗ trợ ACB, MB Bank, BIDV, OCB, VietinBank, VIB, Sacombank, VPBank, PGBank, Shinhan Bank, Co-opBank và Vietcombank
- **Không phí transaction** - Không thu thêm trên mỗi giao dịch

## Cách hoạt động

1. **Tạo payment link** bằng API hoặc Dashboard
2. **Gửi link cho khách** - Khách quét QR hoặc chuyển khoản
3. **ApiPay ghi nhận giao dịch** - Hệ thống khớp giao dịch với payment request
4. **Nhận webhook & thông báo loa** - Hệ thống nhận webhook và loa tại quầy đọc thông báo tiền về tức thì
