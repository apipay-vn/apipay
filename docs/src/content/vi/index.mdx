# Giới thiệu ApiPay

ApiPay là cổng thanh toán API giúp bạn dễ dàng tạo liên kết thanh toán qua chuyển khoản ngân hàng tại Việt Nam.

## Tính năng chính

- **Tạo liên kết thanh toán** qua QR Code hoặc thông tin chuyển khoản
- **Tự động xác nhận** khi có thanh toán
- **Webhook notifications** - Nhận thông báo thanh toán theo thời gian thực
- **Nhiều ngân hàng** - Hỗ trợ Vietcombank, MB, ACB, TPBank, BIDV, Sacombank...
- **Miễn phí** - Không phí transaction

## Cách hoạt động

1. **Tạo payment link** bằng API
2. **Gửi link cho khách** - Khách hàng quét QR hoặc chuyển khoản
3. **Tự động xác nhận** - Hệ thống tự nhận biết khi có thanh toán
4. **Nhận webhook** - Bạn nhận thông báo thanh toán thành công

## Bắt đầu

- **Merchants mới?** Bắt đầu với [Hướng dẫn bắt đầu](/vi/onboarding) để thiết lập tài khoản và nhận thanh toán đầu tiên
