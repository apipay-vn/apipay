# Sandbox

Sandbox Mode là môi trường thử nghiệm riêng biệt, an toàn để bạn kiểm tra toàn bộ luồng tích hợp trước khi chạy thật. Bạn có API key thử, tài khoản ngân hàng ảo và payment request thử — mọi thứ hoạt động giống production, nhưng không có tiền thật và dữ liệu live không bao giờ bị ảnh hưởng.

Không cần gói trả phí — chỉ cần tài khoản đã xác minh và đang hoạt động.

---

## Bật Sandbox Mode

Vào **Sandbox** ở thanh bên trái và bật **Sandbox Mode**.

Khi bật, dashboard chỉ hiển thị dữ liệu sandbox. API key và dữ liệu live của bạn không bao giờ bị ảnh hưởng.

---

## Môi trường thử nghiệm

Sandbox dùng tài nguyên riêng, tách biệt hoàn toàn với production:

- **API key thử** — tạo tại mục API Keys, bắt đầu bằng `ak_test_`
- **Tài khoản ngân hàng ảo** — được tạo khi bạn thêm ngân hàng trong sandbox
- **Payment request thử** — mã công khai bắt đầu bằng `test_pr_`
- **Webhook và giao dịch sandbox** — tách biệt với bản live

---

## Quy trình test

1. Bật **Sandbox Mode**.
2. Tạo API key thử (bắt đầu bằng `ak_test_`).
3. Đăng ký webhook sandbox và tạo một payment request thử.
4. Mô phỏng một giao dịch chuyển tiền.
5. Kiểm tra log gửi webhook để xác nhận luồng hoạt động.
6. Xóa lịch sử hoặc reset sandbox bất cứ lúc nào.

---

## Mô phỏng giao dịch

Có hai cách:

- **Trang Transactions** — dùng công cụ mô phỏng giao dịch sandbox để tạo giao dịch thủ công.
- **Trang thanh toán** — mở một payment request thử (`test_pr_`) và thanh toán bằng nút test.

Cả hai cách đều kích hoạt webhook tương ứng đến các webhook sandbox của bạn.

---

## Kiểm tra delivery

Mở log gửi webhook. Một lần gửi thành công xác nhận luồng sandbox hoạt động đúng — payload và chữ ký giống hệt production.

### Payload sandbox

Payload webhook giống production, thêm một trường `"sandbox": true` ở cấp cao nhất để handler phân biệt sự kiện test với sự kiện thật.

```json
{
  "event": "transaction.in",
  "sandbox": true,
  "data": {
    "transactionId": "clxyz...",
    "referenceCode": "test_pr_...",
    "amount": "50000",
    "content": "ORDER-12345",
    "transactionDate": "2026-05-14T10:30:00.000Z",
    "bankAccountPublicId": "bk_abcdef1234567890",
    "gateway": "APIPAY",
    "rawTransactionDate": "2026-05-14 10:30:00",
    "vaNumber": "999988887777",
    "accountNumber": "0123456789"
  }
}
```

### Nhận biết sự kiện sandbox

Trong handler, kiểm tra `sandbox: true` để bỏ qua phần xử lý đơn hàng khi đang test:

```javascript
app.post('/webhooks/apipay', (req, res) => {
  const {event, sandbox, data} = req.body;

  if (sandbox) {
    console.log('[sandbox] nhận sự kiện test:', event, data.referenceCode);
    return res.status(200).json({received: true});
  }

  // xử lý giao dịch thật
  if (event === 'transaction.in') {
    // xử lý đơn hàng...
  }

  res.status(200).json({received: true});
});
```

---

## Xóa lịch sử và reset

- **Xóa lịch sử** — xóa payment request, giao dịch và log gửi trong sandbox. Ngân hàng sandbox, webhook và API key vẫn giữ.
- **Reset sandbox** — xóa toàn bộ tài nguyên sandbox: API key, ngân hàng, webhook và lịch sử. Sandbox Mode vẫn bật; ngân hàng ảo sẽ được tạo lại khi bạn dùng tiếp.

---

## Mẹo

- Dùng [Webhook.site](https://webhook.site) hoặc [ngrok](https://ngrok.com) để test với server local mà chưa cần deploy
- Sandbox dùng API giống hệt production — chỉ cần đổi sang API key thử
- Payment request thử có mã `test_pr_` để bạn luôn phân biệt được với bản live
