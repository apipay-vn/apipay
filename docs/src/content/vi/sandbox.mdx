# Sandbox & Live Test

Có hai cách kiểm thử trước khi nhận tiền thật:

- **Live Test**: giả lập một giao dịch trên tài khoản ngân hàng thật của bạn và gửi tới webhook thật. Không có tiền chuyển đi, dữ liệu thật không bị ảnh hưởng.
- **Sandbox**: môi trường riêng với khóa API thử nghiệm, ngân hàng thử nghiệm và yêu cầu thanh toán thử nghiệm.

Cả hai đều ký webhook bằng header `ApiPay-Signature` giống môi trường thật.

---

## Live Test

Dùng Live Test để kiểm tra endpoint webhook thật mà không phải chờ một giao dịch ngân hàng. Cần gói dịch vụ đang hoạt động và ít nhất một tài khoản ngân hàng đã kết nối.

1. Mở **Chế độ Sandbox** trong dashboard, để nút gạt ở **Live Test**.
2. Chọn tài khoản ngân hàng, nhập số tiền, nội dung và webhook nhận (tất cả webhook áp dụng cho ngân hàng đó, hoặc một webhook cụ thể).
3. Nhấn **Tạo và kích hoạt**. Kết quả hiển thị payload cùng mã và nội dung phản hồi của từng webhook.

### Payload Live Test

Giống payload thật, thêm `"sandbox": true` và `"liveTest": true`. Mã tham chiếu bắt đầu bằng `LVT-`.

```json
{
  "event": "transaction.in",
  "sandbox": true,
  "liveTest": true,
  "data": {
    "transactionId": "clxyz123abc",
    "referenceCode": "LVT-1755298200000-A1B2C3D4",
    "amount": "50000",
    "type": "IN",
    "content": "LIVETEST-ORDER-001",
    "transactionDate": "2026-08-15T10:30:00.000Z",
    "bankAccountPublicId": "bnk_abc123",
    "gateway": "970422",
    "vaNumber": null,
    "accountNumber": "0123456789"
  }
}
```

Mọi sự kiện Live Test đều có `sandbox: true`, nên chỉ cần kiểm tra một cờ:

```javascript
app.post("/webhooks/apipay", express.raw({type: "*/*"}), (req, res) => {
  // Xác thực chữ ký trước, xem trang Webhook
  const {event, sandbox, data} = JSON.parse(req.body.toString("utf8"));

  if (sandbox) {
    console.log("[test] sự kiện thử nghiệm:", event);
    return res.status(200).json({received: true});
  }

  if (event === "transaction.in") {
    // Xử lý đơn hàng thật
  }

  res.status(200).json({received: true});
});
```

Bạn có thể xóa lịch sử Live Test bất cứ lúc nào trong dashboard.

## Sandbox

Sandbox hoạt động như môi trường thật nhưng không có tiền thật và không chạm tới dữ liệu thật. Không cần gói trả phí, chỉ cần tài khoản đã xác minh.

1. Mở **Chế độ Sandbox** trong dashboard và gạt sang **Sandbox**. Dashboard lúc này chỉ hiển thị dữ liệu sandbox.
2. Thêm ngân hàng sandbox, đăng ký webhook sandbox và tạo khóa API thử nghiệm.
3. Gọi API như bình thường bằng khóa thử nghiệm, rồi giả lập thanh toán.

| Tài nguyên | Nhận biết |
| ---------- | --------- |
| Khóa API thử nghiệm | `accessKey` bắt đầu bằng `ak_test_` |
| Ngân hàng sandbox | `publicId` bắt đầu bằng `test_bank_` |
| Yêu cầu thanh toán thử nghiệm | `publicId` bắt đầu bằng `test_pr_` |
| Giao dịch sandbox | `publicId` bắt đầu bằng `test_txn_` |

### Giả lập thanh toán

```bash
POST /v1/payment-requests/:publicId/pay
```

Đánh dấu một yêu cầu thanh toán sandbox là đã trả và gửi webhook tới các webhook sandbox. Không cần xác thực, không có body. Chỉ nhận `publicId` bắt đầu bằng `test_pr_`; mã khác trả `400`.

```bash
curl -X POST https://app.apipay.vn/v1/payment-requests/test_pr_abc123/pay
```

```json
{
  "data": {
    "publicId": "test_pr_abc123",
    "status": "COMPLETED",
    "transaction": {
      "publicId": "test_txn_a1b2c3d4e5f6a7b8",
      "amount": "50000",
      "content": "TEST-ORDER-001",
      "sandbox": true
    },
    "sandbox": true
  },
  "statusCode": 201,
  "timestamp": "2026-08-15T10:30:00.000Z"
}
```

Bạn cũng có thể giả lập trong dashboard: tạo giao dịch thủ công ở trang **Giao dịch**, hoặc mở trang thanh toán của yêu cầu `test_pr_` và bấm nút thanh toán thử.

### Payload sandbox

Webhook sandbox gọn hơn payload thật và có `"sandbox": true`:

```json
{
  "event": "transaction.in",
  "sandbox": true,
  "created": "2026-08-15T10:30:00.000Z",
  "data": {
    "publicId": "test_txn_a1b2c3d4e5f6a7b8",
    "amount": "50000",
    "content": "TEST-ORDER-001",
    "type": "IN",
    "status": "SUCCESS"
  }
}
```

### Xóa lịch sử và đặt lại

- **Xóa lịch sử**: xóa yêu cầu thanh toán, giao dịch và lịch sử gửi webhook trong sandbox. Ngân hàng, webhook và khóa API sandbox vẫn giữ nguyên.
- **Đặt lại sandbox**: xóa toàn bộ dữ liệu sandbox, gồm cả khóa API, ngân hàng và webhook.

## Mẹo

- Dùng [Webhook.site](https://webhook.site) hoặc [ngrok](https://ngrok.com) để nhận webhook trên máy của bạn.
- Sandbox dùng cùng API với môi trường thật, chỉ khác khóa API.
