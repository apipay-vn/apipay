# Hướng dẫn Dashboard

Dashboard ApiPay là nơi bạn quản lý thanh toán, tài khoản ngân hàng và các tích hợp. Trang này tóm tắt những phần bạn sẽ dùng thường xuyên nhất.

---

## Tổng quan Dashboard

Sau khi đăng nhập, bạn sẽ thấy:

- **Thanh bên** - Mở các tính năng chính
- **Header** - Thông tin tài khoản, thông báo, cài đặt
- **Khu vực nội dung chính** - Nội dung của trang hiện tại

### Các phần chính

| Phần | Mô tả |
|--------|-------------|
| Tổng quan | Thống kê nhanh và hoạt động gần đây |
| Yêu cầu thanh toán | Tạo và quản lý link thanh toán |
| Giao dịch | Xem các giao dịch ngân hàng |
| Cài đặt | Tài khoản, ngân hàng, webhook, API keys |

---

## Điều hướng

### Menu thanh bên

```
📊 Tổng quan
   └─ Trang chủ dashboard với các chỉ số chính

💳 Yêu cầu thanh toán
   └─ Tạo và quản lý link thanh toán

📈 Giao dịch
   └─ Xem lịch sử và chi tiết thanh toán

🔊 Tích hợp
   ├─ Loa thanh toán (Thông báo giọng nói tiền về realtime)
   ├─ Tên miền riêng
   ├─ Kênh thông báo
   ├─ API Keys
   └─ Plugin thương mại điện tử (WooCommerce, WHMCS,...)

⚙️ Cài đặt
   ├─ Hồ sơ tài khoản
   ├─ Tài khoản ngân hàng
   ├─ Cài đặt thanh toán
   ├─ Webhooks
   ├─ Đăng ký
   ├─ Giao diện
   └─ Bảo mật & Passkey
```

## Trang Tổng Quan

Trang tổng quan cho bạn cái nhìn nhanh về tình hình thanh toán:

### Chỉ số chính

1. **Tổng doanh thu** - Tổng tất cả thanh toán thành công
2. **Số giao dịch** - Số giao dịch thành công
3. **Tháng này** - Doanh thu và số giao dịch trong tháng
4. **Giao dịch trung bình** - Giá trị trung bình của mỗi giao dịch

### Biểu đồ

- **Timeline giao dịch** - Giao dịch theo thời gian
- **Phân bổ ngân hàng** - Ngân hàng được khách dùng nhiều nhất

### Hoạt động gần đây

- Giao dịch mới nhất với trạng thái
- Thao tác nhanh cho các việc thường dùng

## Yêu cầu thanh toán

Tạo và quản lý link thanh toán cho khách hàng.

### Tạo yêu cầu thanh toán

1. Nhấn **Tạo yêu cầu thanh toán**
2. Điền form:
   - **Ngân hàng** - Chọn tài khoản ngân hàng đã kết nối
   - **Số tiền** - Số tiền thanh toán bằng VND
   - **Nội dung** - Mã hoặc ghi chú chuyển khoản (ví dụ: số đơn hàng)
   - **Tiêu đề** - (Tùy chọn) Mô tả thanh toán
   - **Redirect URL** - Nơi đưa khách về sau khi thanh toán
3. Nhấn **Tạo**

### Tính năng

- **Mã QR** - Tạo sẵn để khách quét bằng app ngân hàng
- **Link thanh toán** - URL có thể chia sẻ cho khách hàng
- **Sao chép** - Sao chép nhanh link hoặc thông tin thanh toán
- **Chia sẻ** - Chia sẻ qua email, chat, v.v.

### Quản lý yêu cầu thanh toán

- **Xem chi tiết** - Mở để xem đầy đủ thông tin
- **Hủy** - Hủy yêu cầu thanh toán không còn dùng
- **Trạng thái** - ĐANG CHỜ, HOÀN THÀNH, HẾT HẠN, ĐÃ HỦY

---

## Commerce

Sản phẩm và mức giá bạn bán, rồi tạo link thanh toán từ mức giá.

1. Mở **Commerce** trên thanh bên.
2. Tạo sản phẩm. Có thể thêm mức giá đầu ngay trong form.
3. Trên trang sản phẩm, bấm **Tạo thanh toán** để mở link đúng số tiền đó.

Giá mặc định của sản phẩm dùng khi bấm **Tạo thanh toán**. Số tiền trên một mức giá không đổi — tạo mức giá mới nếu muốn thu khác. Chi tiết: [Commerce](/vi/commerce).

## Giao dịch

Xem giao dịch ngân hàng và thông tin khớp thanh toán.

### Danh sách giao dịch

| Cột | Mô tả |
|--------|-------------|
| Ngày | Thời điểm nhận giao dịch |
| Tham chiếu | Nội dung hoặc mã thanh toán |
| Số tiền | Số tiền thanh toán |
| Ngân hàng | Ngân hàng nhận giao dịch |
| Trạng thái | Trạng thái giao dịch |

### Lọc & tìm kiếm

- Lọc theo khoảng ngày
- Lọc theo trạng thái
- Tìm kiếm theo tham chiếu hoặc số tiền

### Chi tiết giao dịch

Nhấn bất kỳ giao dịch nào để xem:
- ID giao dịch đầy đủ
- Tài khoản ngân hàng liên quan
- Thời gian thanh toán
- Yêu cầu thanh toán liên quan

## Tích hợp & Tiện ích

### Loa Thanh Toán (Payment Speaker)

Biến điện thoại, máy tính bảng hoặc laptop thành loa đọc thông báo chuyển khoản tiền về tức thì mà không cần mua thiết bị chuyên dụng:

1. Vào **Tích hợp → Loa thanh toán**
2. Chọn tài khoản ngân hàng cần theo dõi và chọn giọng đọc tiếng Việt yêu thích
3. Bấm **Bắt đầu phiên** và sao chép URL phiên mở trên thiết bị tại quầy thu ngân

Xem chi tiết tại [Hướng dẫn Loa Thanh Toán](/vi/payment-speaker).

### Tên miền riêng

Tùy chỉnh tên miền trang thanh toán (ví dụ: `pay.yourbrand.vn`) giúp tăng độ nhận diện và uy tín thương hiệu. Xem [Hướng dẫn Tên miền riêng](/vi/custom-domains).

## Cài đặt

### Hồ sơ tài khoản

Quản lý thông tin cá nhân và doanh nghiệp:

- **Email** - Email đăng nhập
- **Tên** - Tên hiển thị
- **Tên doanh nghiệp** - Hiển thị trên trang thanh toán
- **Mã số thuế** - Để xuất hóa đơn
- **Địa chỉ doanh nghiệp** - Địa chỉ đăng ký

### Tài khoản ngân hàng

- Xem các ngân hàng đã kết nối
- Thêm/xóa tài khoản ngân hàng
- Bật/tắt trạng thái tài khoản

Xem [Quản lý tài khoản ngân hàng](/vi/banking) để biết chi tiết.

### Cài đặt thanh toán

- **Redirect URL mặc định** - Nơi đưa khách về sau khi thanh toán
- **Tiêu đề mặc định** - Mô tả mặc định cho thanh toán

### API Keys

Tạo và quản lý API keys để tích hợp:

1. Nhấn **Tạo Key mới**
2. Đặt tên cho key
3. Sao chép và lưu ở nơi an toàn
4. Dùng key trong API requests

> **Quan trọng:** Hãy giữ `secretKey` an toàn. Sau khi tạo, bạn không thể xem lại key này.

### Webhooks

Tạo webhook endpoint để nhận thông báo gần như ngay lập tức:

1. Thêm webhook URL
2. Chọn loại sự kiện
3. Test endpoint
4. Theo dõi lịch sử gửi

Xem [Tài liệu Webhook](/vi/api/webhooks) để biết chi tiết kỹ thuật.

### Đăng ký

Xem và quản lý gói của bạn:

- Gói hiện tại hoặc trạng thái FREE TRIAL
- Tùy chọn nâng cấp/hạ cấp
- Lịch sử thanh toán
- Ngày gia hạn

Xem [Đăng ký & Thanh toán](/vi/subscription) để biết chi tiết gói và dùng thử.

### Giao diện

Tùy chỉnh trang thanh toán mà khách hàng nhìn thấy:

- **Tên merchant** - Tên doanh nghiệp
- **Logo merchant** - Logo hiển thị trên trang thanh toán
- **Theme** - Chế độ sáng/tối

### Bảo mật

Bảo vệ tài khoản của bạn:

- **Passkey** — Đăng ký passkey (Face ID, vân tay hoặc passkey trên thiết bị) để đăng nhập không cần mật khẩu. Xem [Passkey](/vi/passkeys) để biết chi tiết.
- **Xác thực hai yếu tố (2FA)** — Bật 2FA dựa trên TOTP
- **Đổi mật khẩu** — Cập nhật mật khẩu
- **Lịch sử đăng nhập** — Xem các lần đăng nhập gần đây

## Thao tác nhanh

### Tác vụ thường dùng

| Tác vụ | Nơi tìm |
|------|------------|
| Tạo thanh toán | Yêu cầu thanh toán → Tạo |
| Mở loa thanh toán | Tích hợp → Loa thanh toán |
| Kiểm tra doanh thu | Tổng quan |
| Thêm ngân hàng | Cài đặt → Tài khoản ngân hàng |
| Lấy API key | Tích hợp → API Keys |
| Cấu hình webhook | Cài đặt → Webhooks |

---

## Phím tắt

- `Ctrl/Cmd + K` - Tìm kiếm nhanh
- `Ctrl/Cmd + N` - Yêu cầu thanh toán mới

---

## Mẹo

### Làm việc nhanh hơn

1. **Dùng tìm kiếm nhanh** - Tìm nhanh bằng Ctrl+K
2. **Đánh dấu trang hay dùng** - Mở lại nhanh hơn
3. **Thiết lập mặc định thanh toán** - Tiết kiệm thời gian khi tạo yêu cầu mới
4. **Bật Loa thanh toán tại quầy** - Nhận diện tiền về tức thì mà không cần chuyển màn hình

### Theo dõi vận hành

1. **Bật thông báo** - Nhận cảnh báo cho các sự kiện quan trọng
2. **Kiểm tra dashboard thường xuyên** - Theo dõi xu hướng giao dịch
3. **Xem lại webhooks** - Đảm bảo webhook vẫn gửi thành công
