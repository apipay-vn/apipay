# Hướng dẫn bắt đầu

Chào mừng bạn đến với ApiPay. Trang này đưa bạn đi từ bước tạo tài khoản đến lúc nhận thanh toán đầu tiên.

## Vì sao chọn ApiPay?

ApiPay giúp doanh nghiệp Việt Nam nhận chuyển khoản ngân hàng qua API. Không cần quy trình phức tạp, không phí ẩn theo từng giao dịch. Bạn chỉ cần kết nối ngân hàng, tạo payment request và nhận webhook khi có tiền vào.

## Bạn sẽ làm gì?

Dưới đây là các bước chính:

1. **Đăng ký** - Tạo tài khoản ApiPay
2. **Chọn gói dịch vụ** - Chọn gói phù hợp với nhu cầu
3. **Kết nối ngân hàng** - Liên kết tài khoản ngân hàng Việt Nam
4. **Thiết lập tích hợp** - Tạo API keys và webhook
5. **Nhận thanh toán đầu tiên** - Tạo payment request đầu tiên

---

## Bước 1: Đăng ký

Truy cập [my.apipay.vn](https://my.apipay.vn) và nhấn **Đăng ký**.

Bạn có thể đăng ký bằng:

- **Email & Mật khẩu** - Cách đăng ký quen thuộc
- **Magic Link** - Đăng nhập qua email, không cần nhập mật khẩu

### Mẹo khi đăng ký

- Dùng **email doanh nghiệp** nếu có. Khách hàng sẽ tin tưởng hơn.
- Chọn **mật khẩu mạnh** và bật 2FA sau khi đăng ký.
- Điền sớm thông tin **doanh nghiệp**. Đây là thông tin khách thấy trên trang thanh toán.

---

## Bước 2: Chọn gói dịch vụ

Các gói ApiPay khác nhau chủ yếu ở số lượng tài khoản ngân hàng bạn có thể kết nối:

| Gói        | Giá                 | Tài Khoản Ngân Hàng |
| ---------- | ------------------- | ------------------- |
| BASIC      | 100.000 VND/tháng   | 1 tài khoản         |
| STARTER    | 200.000 VND/tháng   | 3 tài khoản         |
| PRO        | 400.000 VND/tháng   | 5 tài khoản         |
| TEAM       | 700.000 VND/tháng   | 10 tài khoản        |
| BUSINESS   | 1.700.000 VND/tháng | 25 tài khoản        |
| ENTERPRISE | 3.200.000 VND/tháng | 50 tài khoản        |

### Cách chọn

**Bắt đầu nhỏ, rồi nâng cấp khi cần:**

- Doanh nghiệp mới: BASIC hoặc STARTER
- Doanh nghiệp đang tăng trưởng: PRO
- Doanh nghiệp có nhiều giao dịch: TEAM trở lên

Bạn có thể nâng cấp bất kỳ lúc nào. Nếu hạ cấp, thay đổi sẽ áp dụng từ chu kỳ thanh toán tiếp theo.

> **Mẹo:** Có nhiều tài khoản ngân hàng giúp phân bổ khối lượng thanh toán và giảm thời gian chờ trong giờ cao điểm.

---

## Bước 3: Kết nối tài khoản ngân hàng

Sau khi đăng ký, hãy kết nối tài khoản ngân hàng Việt Nam. Đây là bước cần có để ApiPay ghi nhận giao dịch và gửi webhook.

### Ngân hàng được hỗ trợ

ApiPay hỗ trợ các ngân hàng lớn tại Việt Nam:

- ACB
- MB Bank
- BIDV
- OCB
- VietinBank (CTG)
- VIB
- Sacombank (STB)
- VPBank (VPB)
- PGBank (PGB)

### Quy trình kết nối

1. Vào **Cài đặt → Tài khoản ngân hàng**
2. Nhấn **Thêm tài khoản ngân hàng**
3. Chọn ngân hàng từ danh sách
4. Nhập số tài khoản
5. Xác minh bằng OTP gửi đến điện thoại đã đăng ký
6. Tài khoản sẽ hoạt động sau khi xác minh

> **Quan trọng:** Tài khoản ngân hàng phải mang tên doanh nghiệp của bạn (hoặc tên đại diện hợp lệ).

---

## Bước 4: Thiết lập tích hợp

### Lấy API Keys

1. Vào **Tích hợp → API Keys**
2. Nhấn **Tạo API Key mới**
3. Đặt tên cho key (ví dụ: "Production", "Development")
4. Sao chép và lưu keys ở nơi an toàn

Bạn sẽ nhận được:

- `accessKey` - Định danh công khai
- `secretKey` - Giữ bí mật!

Khi gọi API, dùng header `Authorization: Bearer <Auth>`, trong đó `<Auth>` là chuỗi `base64(accessKey:secretKey)`. Xem [Xác thực API](/vi/api/authentication) để biết chi tiết.

### Thiết lập webhook (khuyến nghị)

Webhook giúp hệ thống của bạn biết khi có thanh toán:

1. Vào **Cài đặt → Webhooks**
2. Nhấn **Thêm Webhook**
3. Nhập URL endpoint của bạn
4. Lưu và kiểm tra

## Bước 5: Tạo payment request đầu tiên

### Qua Dashboard

1. Vào **Yêu cầu thanh toán**
2. Nhấn **Tạo yêu cầu thanh toán**
3. Chọn tài khoản ngân hàng đã kết nối
4. Nhập số tiền
5. Thêm nội dung/tham chiếu thanh toán
6. Nhấn **Tạo**

Bạn sẽ nhận được link thanh toán để gửi cho khách.

### Qua API

```javascript
const response = await fetch('https://app.apipay.vn/v1/client/payment-requests', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer <Auth>',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    bankPublicId: 'your-bank-id',
    amount: 100000,
    content: 'ORDER-12345',
  }),
});

const {payUrl, qrUrl} = await response.json();
// Chia sẻ payUrl hoặc qrUrl với khách hàng
```

## Mẹo triển khai

### Để bắt đầu suôn sẻ

1. **Test với số tiền nhỏ** - Tạo vài thanh toán 1.000 VND để kiểm tra luồng.
2. **Tạo webhook trước** - Tránh bỏ lỡ thông báo thanh toán.
3. **Thiết lập redirect URL** - Đưa khách về website của bạn sau khi thanh toán.
4. **Tùy chỉnh trang thanh toán** - Thêm tên và logo doanh nghiệp.

### Để vận hành lâu dài

1. **Dùng nhiều tài khoản ngân hàng** - Chia tải giữa các ngân hàng.
2. **Theo dõi analytics giao dịch** - Xem xu hướng thanh toán trên dashboard.
3. **Bật 2FA** - Thêm lớp bảo vệ cho tài khoản.
4. **Giữ API keys an toàn** - Không đưa `secretKey` vào code phía client.
