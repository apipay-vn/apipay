# Vibe Code

Vibe Code generates a ready-made prompt to paste into an AI coding assistant (Claude Code, Cursor…) so it can integrate ApiPay into your project: create payment requests, redirect customers to the payment page, and receive webhooks.

<Callout type="tip">
Open **Integrations > Web App > Vibe Code** in the dashboard to generate the prompt.

[Open Vibe Code in dashboard](https://my.apipay.vn/en/integrations/vibe-code)
</Callout>

## Before You Start

- Create an API key in **Integrations > Web App > API Keys**.
- Connect at least one account in **Banks**.

## Generate the Prompt

1. In the ApiPay dashboard, open **Integrations > Web App > Vibe Code**.
2. Select the default bank account for payment requests.
3. Copy the prompt and paste it into your AI coding assistant.
4. Provide `accessKey` and `secretKey` as environment variables, never in the prompt or source code.

## What the Prompt Asks For

- Read your project structure and existing API patterns.
- Create payment requests through the ApiPay API.
- Redirect customers to the returned `payUrl`.
- Add an endpoint that receives payment webhooks.

## Verify the Integration

- Checkout creates a payment request with the selected `bankPublicId`.
- Customers are redirected to the ApiPay payment page.
- Your result page handles the customer's return from ApiPay.
- Your webhook endpoint returns HTTP 200 right away.

## Troubleshooting

If the prompt cannot be generated, check:

- You have created an API key.
- The selected bank account still exists and is active.
