# WooCommerce

The ApiPay plugin sends customers to the ApiPay payment page at checkout and updates the order automatically once they have paid. It supports both the classic checkout and the Checkout Block.

ApiPay supports VND orders only.

<Callout type="tip">
Open **Integrations > Web App > WooCommerce** in the dashboard to download the preconfigured plugin.

[Open WooCommerce in dashboard](https://my.apipay.vn/en/integrations/woocommerce)
</Callout>

## Install the Plugin

1. In the ApiPay dashboard, open **Integrations > Web App > WooCommerce**.
2. Select the bank account that receives payments and, optionally, a custom domain.
3. Download `apipay-woocommerce.zip`.
4. In WordPress, open **Plugins > Add New > Upload Plugin** and upload the ZIP.
5. Activate **ApiPay for WooCommerce**.

## Enable the Payment Method

Open **WooCommerce > Settings > Payments > ApiPay**, enable the payment method, and save. The plugin comes with the connection details filled in; no changes needed.

## Test a Payment

1. Place an order and choose **Bank transfer via ApiPay** at checkout.
2. Confirm you are redirected to the ApiPay payment page.
3. Transfer the exact amount with the displayed content.
4. Once the transfer succeeds, the order moves to `processing`.

## Troubleshooting

ApiPay sends payment notifications to:

```text
https://your-wordpress-site.com/?wc-api=apipay_woocommerce
```

If an order does not update, check:

- The WordPress site is publicly reachable over HTTPS.
- Security plugins or firewalls are not blocking the `wc-api=apipay_woocommerce` endpoint.
- The API key in the plugin is still active in the dashboard.
