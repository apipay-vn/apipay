# Web App

Create a payment request on your server, redirect the customer to `payUrl`, then receive the result through a redirect or a webhook. No SDK required.

## Before You Start

- Create an API key in [**Integrations > Web App > API Keys**](https://my.apipay.vn/en/integrations/api-keys).
- Connect at least one account in **Banks**.
- Store `APIPAY_ACCESS_KEY`, `APIPAY_SECRET_KEY`, and `APIPAY_BANK_PUBLIC_ID` in environment variables.
- Call ApiPay from your server only, never from the browser.

## Create a Payment Request

Copy into your server-side code.

<CodeTabs>
```javascript
const API_BASE = "https://app.apipay.vn";

const auth = Buffer.from(
  `${process.env.APIPAY_ACCESS_KEY}:${process.env.APIPAY_SECRET_KEY}`,
).toString("base64");

async function createPayment(params) {
  const response = await fetch(`${API_BASE}/v1/client/payment-requests`, {
    method: "POST",
    headers: {
      Authorization: `Bearer ${auth}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      bankPublicId: process.env.APIPAY_BANK_PUBLIC_ID,
      ...params,
    }),
  });

  if (!response.ok) {
    throw new Error(`ApiPay request failed: ${response.status}`);
  }

  const { data } = await response.json();
  return data;
}

const payment = await createPayment({
  amount: "100000",
  content: "ORDER-001",
  title: "Payment for Order #001",
  redirectUrl: "https://your-site.com/payment/result",
});

console.log(payment.payUrl);
```

```python
import base64
import os

import requests

API_BASE = "https://app.apipay.vn"
AUTH = base64.b64encode(
  f"{os.environ['APIPAY_ACCESS_KEY']}:{os.environ['APIPAY_SECRET_KEY']}".encode()
).decode()


def create_payment(**params) -> dict:
  response = requests.post(
    f"{API_BASE}/v1/client/payment-requests",
    json={"bankPublicId": os.environ["APIPAY_BANK_PUBLIC_ID"], **params},
    headers={"Authorization": f"Bearer {AUTH}"},
    timeout=15,
  )
  response.raise_for_status()
  return response.json()["data"]


payment = create_payment(
  amount="100000",
  content="ORDER-001",
  title="Payment for Order #001",
  redirectUrl="https://your-site.com/payment/result",
)

print(payment["payUrl"])
```

```php
<?php

const API_BASE = 'https://app.apipay.vn';

function createPayment(array $params): array
{
  $auth = base64_encode(getenv('APIPAY_ACCESS_KEY') . ':' . getenv('APIPAY_SECRET_KEY'));

  $ch = curl_init(API_BASE . '/v1/client/payment-requests');
  curl_setopt_array($ch, [
    CURLOPT_POST => true,
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_TIMEOUT => 15,
    CURLOPT_HTTPHEADER => [
      "Authorization: Bearer {$auth}",
      'Content-Type: application/json',
    ],
    CURLOPT_POSTFIELDS => json_encode(['bankPublicId' => getenv('APIPAY_BANK_PUBLIC_ID')] + $params),
  ]);

  $body = curl_exec($ch);
  $status = curl_getinfo($ch, CURLINFO_HTTP_CODE);

  if ($body === false || $status >= 400) {
    throw new RuntimeException("ApiPay request failed: {$status}");
  }

  return json_decode($body, true)['data'];
}

$payment = createPayment([
  'amount' => '100000',
  'content' => 'ORDER-001',
  'title' => 'Payment for Order #001',
  'redirectUrl' => 'https://your-site.com/payment/result',
]);

echo $payment['payUrl'];
```

Store `publicId` and `redirectSecret` with your order, then redirect the customer to `payUrl`.

## Handle the Payment Result

**Redirect:** after payment, the customer returns to `redirectUrl` with `data` and `signature` query parameters. Verify them with `redirectSecret` before showing a paid state. See [Payment Requests API](/en/api/payment-requests).

**Webhook:** open **Webhooks** in the dashboard to register an endpoint for payment notifications. Every webhook carries an `ApiPay-Signature` header for you to verify. See [Webhooks](/en/api/webhooks).

## Production Checklist

- Use a unique `content` value for each order.
- Verify redirect and webhook signatures before marking an order paid.
- Webhooks can arrive more than once; make sure each order is updated only once.
- Return HTTP 200 from your webhook route right away and do heavy work in the background.
