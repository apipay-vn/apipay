# WHMCS

The ApiPay module lets customers pay WHMCS invoices by bank transfer through the ApiPay payment page. Invoices must be in VND.

<Callout type="tip">
Open **Integrations > Web App > WHMCS** in the dashboard to download the preconfigured module.

[Open WHMCS in dashboard](https://my.apipay.vn/en/integrations/whmcs)
</Callout>

## Before You Start

- Create an API key in **Integrations > Web App > API Keys**.
- Connect at least one account in **Banks**.
- Optional: verify a [custom domain](/en/custom-domains) for the payment page.

## Download the Module

1. In the ApiPay dashboard, open **Integrations > Web App > WHMCS**.
2. Select the bank account that receives payments and, optionally, a custom domain.
3. Download `apipay-whmcs.zip`.

## Install in WHMCS

1. Extract the ZIP into your WHMCS root folder. The files land under `modules/gateways/` and `modules/gateways/callback/`.
2. Open **WHMCS Admin > System Settings > Payment Gateways**.
3. Activate **ApiPay Gateway**.
4. Review the prefilled settings (no changes needed) and save.

## Test a Payment

1. Create an invoice and choose **ApiPay** as the payment method.
2. Confirm the customer is redirected to the ApiPay payment page.
3. Transfer the exact amount with the displayed content.
4. Once the transfer succeeds, the invoice is marked paid in WHMCS.

## Troubleshooting

If an invoice does not update, check:

- The WHMCS site is publicly reachable over HTTPS and no firewall or security rule blocks the callback.
- The API key in WHMCS is still active in the dashboard.
- If you use a custom domain, it is verified.
