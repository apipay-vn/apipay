# Welcome to ApiPay

ApiPay is a payment gateway API that helps you easily create payment links via bank transfer in Vietnam.

![ApiPay documentation overview](/apipay-docs.jpg)

## Key Features

- **Create payment links** via QR Code or bank transfer details
- **Automatic confirmation** when payment is received
- **Free Payment Speaker** - Real-time voice announcements for incoming bank transfers on any device
- **Webhook notifications** - Receive real-time payment notifications
- **Multiple banks** - Supports ACB, MB Bank, BIDV, OCB, VietinBank, VIB, Sacombank, VPBank, PGBank, Shinhan Bank, Co-opBank, and Vietcombank
- **No transaction fees** - Zero fee per transaction

## How It Works

1. **Create payment link** via API or Dashboard
2. **Send link to customer** - Customer scans QR or transfers
3. **Automatic confirmation** - System detects payment automatically
4. **Receive webhook & voice alerts** - Your backend receives webhook and counter speaker announces payment immediately
