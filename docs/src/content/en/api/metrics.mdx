# Metrics API

API for retrieving transaction metrics and analytics data.

## Overview

Get an overview of your transaction metrics including totals, counts, and averages.

```bash
GET /v1/client/metrics/overview
```

### Headers

| Header | Description |
|--------|-------------|
| `Authorization` | `Bearer <Auth>` |

### Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `period` | string | — | Time period: `today`, `this_week`, `last_week`, `this_month`, `last_month`, `last_3_months`, `last_6_months`, `this_year`, `custom` |
| `dateFrom` | string | — | Start date (ISO 8601) |
| `dateTo` | string | — | End date (ISO 8601) |
| `search` | string | — | Search by reference code, content, account number, bank name, bank code, or VA number |

### Response

```json
{
  "data": {
    "totalIn": 5000000,
    "totalOut": 0,
    "totalTransactions": 50,
    "averageAmount": 115000,
    "successRate": 90,
    "byBank": [
      {
        "bankName": "MB",
        "accountNumber": "0123456789",
        "totalIn": 3000000,
        "countIn": 30,
        "totalOut": 0,
        "countOut": 0
      }
    ]
  }
}
```

## Time Series

Get time series data for charts.

```bash
GET /v1/client/metrics/time-series
```

### Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `period` | string | — | Time period |
| `dateFrom` | string | — | Start date (ISO 8601) |
| `dateTo` | string | — | End date (ISO 8601) |
| `granularity` | string | — | Data granularity: `daily`, `weekly`, `monthly` |

### Response

```json
{
  "data": [
    {
      "date": "2026-03-01",
      "totalIn": 1000000,
      "totalOut": 0,
      "count": 10
    },
    {
      "date": "2026-03-02",
      "totalIn": 1500000,
      "totalOut": 0,
      "count": 15
    }
  ]
}
```

## Daily Transactions

Get hourly transaction activity for a specific Vietnam date.

```bash
GET /v1/client/metrics/hourly-transactions
```

### Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `date` | string | — | Date in `YYYY-MM-DD` format, interpreted in the `Asia/Ho_Chi_Minh` timezone. Defaults to today in Vietnam. |
| `status` | string[] | — | Filter by transaction status: `SUCCESS`, `FAILED`, `PENDING` |
| `bankAccountId` | number[] | — | Filter by one or more bank account IDs |

### Response

```json
{
  "data": [
    {
      "hour": 0,
      "label": "00:00",
      "SUCCESS_amount": 2500000,
      "SUCCESS_count": 5,
      "FAILED_amount": 0,
      "FAILED_count": 0,
      "PENDING_amount": 100000,
      "PENDING_count": 1,
      "total_amount": 2600000,
      "total_count": 6
    },
    {
      "hour": 1,
      "label": "01:00",
      "SUCCESS_amount": 0,
      "SUCCESS_count": 0,
      "FAILED_amount": 0,
      "FAILED_count": 0,
      "PENDING_amount": 0,
      "PENDING_count": 0,
      "total_amount": 0,
      "total_count": 0
    }
  ]
}
```

## Transactions List

Get paginated list of transactions.

```bash
GET /v1/client/metrics/transactions
```

### Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `period` | string | — | Time period |
| `dateFrom` | string | — | Start date (ISO 8601) |
| `dateTo` | string | — | End date (ISO 8601) |
| `search` | string | — | Search by reference code, content, account number, bank name, bank code, or VA number |
| `page` | number | — | Page number (default: 1) |
| `limit` | number | — | Items per page (default: 20, max: 100) |
| `sortBy` | string | — | Sort field: `transactionDate`, `amount`, `createdAt` |
| `sortOrder` | string | — | Sort order: `asc`, `desc` |

### Response

```json
{
  "data": {
    "data": [
      {
        "id": "txn_abc123",
        "amount": "100000",
        "type": "IN",
        "content": "ORDER-001",
        "referenceCode": "TX123456789",
        "transactionDate": "2026-03-06T10:05:00Z",
        "status": "SUCCESS",
        "createdAt": "2026-03-06T10:00:00Z",
        "bankAccount": {
          "bankShortName": "MB",
          "bankName": "MB Bank",
          "accountNumber": "0123456789",
          "vaNumber": "VA123456789",
          "accountName": "NGUYEN VAN A"
        }
      }
    ],
    "meta": {
      "total": 50,
      "page": 1,
      "limit": 20,
      "totalPages": 3
    }
  }
}
```
