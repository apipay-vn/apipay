# Metrics API

Look up received transactions and summary figures. Every request needs the header `Authorization: Bearer <Auth>` (see [API Authentication](/en/api/authentication)).

## Time filters

The endpoints below accept the same time filters:

| Parameter  | Type   | Required | Description                                                                                                     |
| ---------- | ------ | -------- | --------------------------------------------------------------------------------------------------------------- |
| `period`   | string | No       | `today`, `yesterday`, `this_week`, `last_week`, `this_month`, `last_month`, `last_3_months`, `last_6_months`, `this_year`, `custom` |
| `dateFrom` | string | No       | From date, `YYYY-MM-DD` (Vietnam time). Use with `period=custom`                                                 |
| `dateTo`   | string | No       | Through date, `YYYY-MM-DD` (Vietnam time). Use with `period=custom`                                              |

## List transactions

```bash
GET /v1/client/metrics/transactions
```

In addition to the time filters:

| Parameter       | Type     | Required | Description                                                  |
| --------------- | -------- | -------- | ------------------------------------------------------------ |
| `search`        | string   | No       | Search by reference code, description, account or VA number  |
| `bankPublicId`  | string[] | No       | Filter by bank account. Repeat to filter several             |
| `accountNumber` | string   | No       | Filter by account or VA number                               |
| `sortBy`        | string   | No       | `transactionDate` (default), `amount` or `createdAt`         |
| `sortOrder`     | string   | No       | `desc` (default) or `asc`                                    |
| `page`          | number   | No       | Default `1`                                                  |
| `limit`         | number   | No       | Default `20`, max `100`                                      |

```bash
curl -G https://app.apipay.vn/v1/client/metrics/transactions \
  -H "Authorization: Bearer <Auth>" \
  --data-urlencode "period=today" \
  --data-urlencode "search=ORDER-12345"
```

## Get a transaction

`id` is the `transactionId` from the [webhook](/en/api/webhooks). The response matches one item of the transaction list.

```bash
GET /v1/client/metrics/transactions/:id
```

## Overview

Total received, transaction count and average amount for the selected period.

```bash
GET /v1/client/metrics/overview
```

```bash
curl -G https://app.apipay.vn/v1/client/metrics/overview \
  -H "Authorization: Bearer <Auth>" \
  --data-urlencode "period=this_month"
```

```json
{
  "data": {
    "totalIn": 5000000,
    "totalTransactions": 50,
    "averageAmount": 100000,
    "comparison": null
  },
  "statusCode": 200,
  "timestamp": "2026-08-12T10:35:00.000Z"
}
```

| Field               | Type           | Description                                               |
| ------------------- | -------------- | --------------------------------------------------------- |
| `totalIn`           | number         | Total received (VND)                                      |
| `totalTransactions` | number         | Transaction count                                         |
| `averageAmount`     | number         | Average amount per transaction (VND)                      |
| `comparison`        | object \| null | Comparison with the previous period. Only for `period=this_month` |
