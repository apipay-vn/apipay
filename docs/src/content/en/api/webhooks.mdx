# Webhooks

Webhooks allow you to receive real-time notifications when payment events occur.

## Configure Webhook

Configure webhook URL in the dashboard at **Settings → Webhooks**.

## Events

### payment.completed

When payment is successfully confirmed.

```json
{
  "event": "payment.completed",
  "timestamp": "2026-03-06T10:30:00Z",
  "data": {
    "publicId": "ckabcdef1234567890",
    "amount": "100000",
    "content": "ORDER-12345",
    "transactionId": "TXN-123456789",
    "completedAt": "2026-03-06T10:30:00Z",
    "bankCode": "MB",
    "accountNumber": "0123456789"
  }
}
```

### payment.expired

When a payment link expires without payment.

```json
{
  "event": "payment.expired",
  "timestamp": "2026-03-06T23:59:59Z",
  "data": {
    "publicId": "ckabcdef1234567890",
    "amount": "100000",
    "content": "ORDER-12345",
    "expiredAt": "2026-03-06T23:59:59Z"
  }
}
```

### payment.cancelled

When a payment link is cancelled.

```json
{
  "event": "payment.cancelled",
  "timestamp": "2026-03-06T15:00:00Z",
  "data": {
    "publicId": "ckabcdef1234567890",
    "cancelledAt": "2026-03-06T15:00:00Z"
  }
}
```

## Webhook Authentication

All webhook requests include an `ApiPay-Signature` header for verification.

### Node.js

```javascript
const crypto = require('crypto');

function verifyWebhookSignature(payload, signature, secretKey) {
  const expectedSignature = crypto
    .createHmac('sha256', secretKey)
    .update(payload)
    .digest('hex');

  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expectedSignature)
  );
}

// Usage in Express
app.post('/webhook', (req, res) => {
  const signature = req.headers['x-apipay-signature'];
  const payload = JSON.stringify(req.body);

  if (!verifyWebhookSignature(payload, signature, process.env.WEBHOOK_SECRET)) {
    return res.status(401).json({ error: 'Invalid signature' });
  }

  // Process webhook
  const { event, data } = req.body;

  if (event === 'payment.completed') {
    console.log('Payment completed:', data.publicId);
    // Update order in your database
  }

  res.status(200).json({ received: true });
});
```

### Python

```python
import hmac
import hashlib

def verify_webhook_signature(payload: str, signature: str, secret_key: str) -> bool:
    expected_signature = hmac.new(
        secret_key.encode(),
        payload.encode(),
        hashlib.sha256
    ).hexdigest()

    return hmac.compare_digest(signature, expected_signature)

# Usage in Flask
@app.route('/webhook', methods=['POST'])
def handle_webhook():
    signature = request.headers.get('ApiPay-Signature')
    payload = request.get_data(as_text=True)

    if not verify_webhook_signature(payload, signature, WEBHOOK_SECRET):
        return {'error': 'Invalid signature'}, 401

    data = request.get_json()
    event = data.get('event')

    if event == 'payment.completed':
        print(f"Payment completed: {data['data']['publicId']}")
        # Update order

    return {'received': True}, 200
```

## Retry Policy

If webhook delivery fails, the system will retry:

- Attempt 1: Immediately
- Attempt 2: After 5 seconds
- Attempt 3: After 20 seconds
- Attempt 4: After 1 minute

After 3 failed retry attempts, the webhook will be disabled.

## Testing Webhooks

Use [Webhook.site](https://webhook.site) to test webhooks during development:

1. Create a test URL at webhook.site
2. Configure the webhook URL in the dashboard
3. Create a payment and complete the transaction
4. View the request on webhook.site

## Best Practices

1. **Always verify signature** before processing webhook
2. **Respond quickly** - Return 200 immediately, process asynchronously
3. **Idempotent** - Handle duplicate events without errors
4. **Log events** - Keep logs for debugging if needed
