# Webhooks

Webhooks allow you to receive real-time notifications when payment events occur.

## Register Webhook

Configure webhook URL in the dashboard at **Settings → Webhooks**, or create one with the API.

```bash
POST /v1/client/webhooks
```

### Request Body

| Parameter      | Type   | Required       | Description                                      |
| -------------- | ------ | -------------- | ------------------------------------------------ |
| `webhookUrl`   | string | **✓ Yes** | HTTPS URL to receive webhook notifications       |
| `bankPublicId` | string | **✓ Yes** | Public ID of the bank account                    |
| `type`         | string | **✓ Yes** | Transaction events: `IN`, `OUT`, or `ALL`        |

### Response

```json
{
	"data": {
		"message": "Tạo webhook thành công",
		"id": "wh_abc123",
		"bankPublicId": "bnk_abc123",
		"webhookUrl": "https://your-domain.com/webhooks/apipay",
		"type": "IN",
		"secret": "a1b2c3d4..."
	}
}
```

Keep `secret`; it is used to verify `ApiPay-Signature`.

## Manage Webhooks

| Endpoint | Description |
| -------- | ----------- |
| `GET /v1/client/webhooks` | List registered webhooks (`page`, `limit`) |
| `PATCH /v1/client/webhooks/:id` | Update `webhookUrl` or `type` |
| `PATCH /v1/client/webhooks/:id/toggle` | Enable or disable a webhook |
| `DELETE /v1/client/webhooks/:id` | Delete a webhook |
| `GET /v1/client/webhooks/:id/history` | View delivery history (`page`, `limit`) |
| `POST /v1/client/webhooks/history/:historyId/resend` | Retry a failed delivery |

### Data Fields

| Field                      | Type   | Description                                       |
| -------------------------- | ------ | ------------------------------------------------- |
| `event`                    | string | Event type: `transaction.in` or `transaction.out` |
| `data.transactionId`       | string | Internal transaction ID (UUID)                    |
| `data.referenceCode`       | string | Bank transaction reference code                   |
| `data.amount`              | number | Transaction amount in VND                         |
| `data.type`                | string | Transaction type: `IN` or `OUT`                   |
| `data.content`             | string | Transaction content/memo                          |
| `data.transactionDate`     | string | Transaction timestamp (ISO 8601)                  |
| `data.bankAccountPublicId` | string | Public ID of the bank account                     |
| `data.gateway`             | string | Bank code (e.g., BIDV, ACB, MBB, OCB)             |
| `data.rawTransactionDate`  | string | Original transaction date from bank               |
| `data.vaNumber`            | string | Virtual account number (optional)                 |
| `data.accountNumber`       | string | Sender/receiver account number                    |

## Webhook Authentication

All webhook requests include an `ApiPay-Signature` header for verification.

<CodeTabs>
```javascript
const crypto = require("crypto");

function verifyWebhookSignature(payload, signature, secretKey) {
	const expectedSignature = crypto
		.createHmac("sha256", secretKey)
		.update(payload)
		.digest("hex");

	return crypto.timingSafeEqual(
		Buffer.from(signature),
		Buffer.from(expectedSignature),
	);
}

// Usage in Express
app.post("/webhook", (req, res) => {
	const signature = req.headers["apipay-signature"];
	const payload = JSON.stringify(req.body);

	if (!verifyWebhookSignature(payload, signature, process.env.WEBHOOK_SECRET)) {
		return res.status(401).json({error: "Invalid signature"});
	}

	// Process webhook
	const {event, data} = req.body;

	if (event === "transaction.in") {
		console.log("Money received:", data.amount);
		console.log("Reference:", data.referenceCode);
		console.log("Content:", data.content);
		// Update order in your database
	} else if (event === "transaction.out") {
		console.log("Money sent:", data.amount);
		console.log("Reference:", data.referenceCode);
	}

	res.status(200).json({received: true});
});
```

```python
import hmac
import hashlib

def verify_webhook_signature(payload: str, signature: str, secret_key: str) -> bool:
    expected_signature = hmac.new(
        secret_key.encode(),
        payload.encode(),
        hashlib.sha256
    ).hexdigest()

    return hmac.compare_digest(signature, expected_signature)

# Usage in Flask
@app.route('/webhook', methods=['POST'])
def handle_webhook():
    signature = request.headers.get('ApiPay-Signature')
    payload = request.get_data(as_text=True)

    if not verify_webhook_signature(payload, signature, WEBHOOK_SECRET):
        return {'error': 'Invalid signature'}, 401

    data = request.get_json()
    event = data.get('event')

    if event == 'transaction.in':
        print(f"Money received: {data['data']['amount']}")
        print(f"Reference: {data['data']['referenceCode']}")
        print(f"Content: {data['data']['content']}")
        # Update order
    elif event == 'transaction.out':
        print(f"Money sent: {data['data']['amount']}")
        # Handle outgoing transaction

    return {'received': True}, 200
```

```php
<?php

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Route;

function verifyWebhookSignature(string $payload, string $signature, string $secretKey): bool
{
    $expectedSignature = hash_hmac('sha256', $payload, $secretKey);

    return hash_equals($expectedSignature, $signature);
}

// Usage in Laravel route
Route::post('/webhook', function (Request $request) {
    $signature = $request->header('ApiPay-Signature');
    $payload = $request->getContent();

    if (!verifyWebhookSignature($payload, $signature, config('services.apipay.webhook_secret'))) {
        return response()->json(['error' => 'Invalid signature'], 401);
    }

    $data = $request->json()->all();
    $event = $data['event'] ?? null;

    if ($event === 'transaction.in') {
        logger('Money received: ' . $data['data']['amount']);
        logger('Reference: ' . $data['data']['referenceCode']);
        logger('Content: ' . $data['data']['content']);
        // Update order in your database
    } elseif ($event === 'transaction.out') {
        logger('Money sent: ' . $data['data']['amount']);
        logger('Reference: ' . $data['data']['referenceCode']);
    }

    return response()->json(['received' => true]);
});
```

## Retry Policy

- Attempt 0: Immediately

If webhook delivery fails, the system will retry:

- Attempt 1: After 5 seconds
- Attempt 2: After 20 seconds
- Attempt 3: After 1 minute

After 3 failed retry attempts, the webhook will be disabled.

## Testing Webhooks

Use [Webhook.site](https://webhook.site) to test webhooks during development:

1. Create a test URL at webhook.site
2. Configure the webhook URL in the dashboard
3. Create a payment and complete the transaction
4. View the request on webhook.site

## Best Practices

1. **Always verify signature** before processing webhook
2. **Respond quickly** - Return 200 immediately, process asynchronously
3. **Idempotent** - Handle duplicate events without errors
4. **Log events** - Keep logs for debugging if needed
