# Bank Management

Connect a bank account and get the `publicId` you use to create payment requests. Every endpoint lives under `/v1/client/banks` and needs [authentication](/en/api/authentication).

Every response is wrapped in `{"data": ..., "statusCode": 200, "timestamp": "..."}`; lists are in `data.message`, pagination in `data.pagination`.

## List supported banks

```bash
GET /v1/client/banks/available
```

Returns the banks that accept new connections, with their account types and the details each bank needs.

```json
{
  "data": {
    "status": true,
    "message": [
      {
        "bankCode": "MBB",
        "bankName": "Ngân hàng TMCP Quân đội",
        "bankBin": "970422",
        "shortName": "MB Bank",
        "logoUrl": "https://...",
        "accountTypes": [
          {"type": "personal-account", "manualActivation": false, "generatesVa": true},
          {"type": "business-account", "manualActivation": false, "generatesVa": true}
        ],
        "requiresIdentity": true,
        "noTransferContent": false,
        "availability": "available"
      }
    ]
  },
  "statusCode": 200,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```

| Field | Type | Description |
| ----- | ---- | ----------- |
| `bankBin` | string | Bank BIN, used when connecting an account |
| `accountTypes[].type` | string | An account type the bank supports |
| `accountTypes[].manualActivation` | boolean | `true` if ApiPay activates this account type manually |
| `accountTypes[].generatesVa` | boolean | `true` if ApiPay issues a virtual account (VA) instead of using the original account number |
| `requiresIdentity` | boolean | `true` if `identity` is required when connecting |
| `noTransferContent` | boolean | `true` if transactions from this bank arrive without transfer content |

## Connect a bank account

```bash
POST /v1/client/banks
```

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `bankBin` | string | Yes | BIN from the supported banks list |
| `bankName` | string | Yes | Bank display name |
| `accountType` | string | Yes | `personal-account`, `business-account` or `business-household-account` |
| `accountNumber` | string | Yes | Bank account number |
| `accountName` | string | Yes | Account holder name, uppercase without diacritics |
| `mobile` | string | Yes | Phone number registered with the bank |
| `identity` | string | Per bank | Citizen ID or tax code. Required when `requiresIdentity` is `true` |
| `acbUserId` | string | Per bank | ACB OneBiz username, required for ACB business and household business accounts |
| `nickname` | string | No | Label shown only in your dashboard (max 50 characters) |

```bash
curl -X POST https://app.apipay.vn/v1/client/banks \
  -H "Authorization: Bearer <Auth>" \
  -H "Content-Type: application/json" \
  -d '{
    "bankBin": "970422",
    "bankName": "MB Bank",
    "accountType": "personal-account",
    "accountNumber": "0123456789",
    "accountName": "NGUYEN VAN A",
    "mobile": "0901234567",
    "identity": "001234567890",
    "nickname": "Shop online"
  }'
```

```json
{
  "data": {
    "status": true,
    "OTP": 1,
    "message": "Vui lòng nhập mã OTP để hoàn tất liên kết tài khoản ngân hàng",
    "bank": {
      "publicId": "bnk_abc123",
      "vaNumber": null,
      "status": "PENDING"
    }
  },
  "statusCode": 201,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```

What to do next depends on the response:

| Response | Meaning |
| -------- | ------- |
| `OTP: 1` | The bank sent an OTP. Call [Confirm OTP](#confirm-otp). |
| `OTP: 0`, `bank.status: "ACTIVE"` | The account is active. |
| `activationRequested: true` | The account is `PENDING`. ApiPay will contact you to finish activation. |
| `requiresAuthorize: true` | Open `authorizeLink` and approve the connection in the bank's app. |

## Confirm OTP

```bash
POST /v1/client/banks/confirm-otp
```

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `bankBin` | string | Yes | BIN used when connecting |
| `accountNumber` | string | Yes | Account number used when connecting |
| `otpNumber` | string | Yes | OTP sent by the bank |

```bash
curl -X POST https://app.apipay.vn/v1/client/banks/confirm-otp \
  -H "Authorization: Bearer <Auth>" \
  -H "Content-Type: application/json" \
  -d '{"bankBin": "970422", "accountNumber": "0123456789", "otpNumber": "123456"}'
```

```json
{
  "data": {
    "status": true,
    "message": "Xác nhận ngân hàng thành công"
  },
  "statusCode": 201,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```

## List connected accounts

```bash
GET /v1/client/banks
```

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `page` | number | No | Page, default `1` |
| `limit` | number | No | Items per page, default `20`, max `50` |
| `search` | string | No | Match account number, holder name, nickname, VA number or bank |
| `status` | string | No | `ACTIVE`, `INACTIVE` or `PENDING` |

```bash
curl "https://app.apipay.vn/v1/client/banks?status=ACTIVE" \
  -H "Authorization: Bearer <Auth>"
```

```json
{
  "data": {
    "status": true,
    "message": [
      {
        "publicId": "bnk_abc123",
        "bankName": "MB Bank",
        "bankShortName": "MB",
        "accountNumber": "0123456789",
        "accountName": "NGUYEN VAN A",
        "nickname": "Shop online",
        "vaNumber": "VA001",
        "status": "ACTIVE",
        "manualActivationPending": false,
        "createdAt": "2026-04-25T10:00:00.000Z"
      }
    ],
    "pagination": {"page": 1, "limit": 20, "total": 1, "totalPages": 1}
  },
  "statusCode": 200,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```

| Field | Type | Description |
| ----- | ---- | ----------- |
| `publicId` | string | Account ID, pass it as `bankPublicId` when creating a payment request |
| `vaNumber` | string \| null | Virtual account number, if any |
| `status` | string | `ACTIVE` in use, `INACTIVE` turned off, `PENDING` waiting for OTP or activation |
| `manualActivationPending` | boolean | `true` while ApiPay is processing a manual activation |

## Get an account

```bash
GET /v1/client/banks/:publicId
```

`data.message` has the same shape as one list item. When the account is not found the API still returns `200`:

```json
{
  "data": {
    "status": false,
    "message": null
  },
  "statusCode": 200,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```

## Turn an account on or off

```bash
PATCH /v1/client/banks/:publicId/status
```

Switches the account between `ACTIVE` and `INACTIVE`. Not available for `PENDING` accounts. If you have turned on a passkey or authenticator app for your ApiPay account, the API returns `403`; turn the bank on or off in the dashboard instead.

```json
{
  "data": {
    "status": true,
    "message": "Cập nhật trạng thái ngân hàng thành công"
  },
  "statusCode": 200,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```

## Rename an account

```bash
PATCH /v1/client/banks/:publicId
```

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `nickname` | string | No | Label, max 50 characters. Send an empty string to clear it |

The nickname shows only in your dashboard, never to customers. The response returns the updated account in `data.bank`.

## Disconnect an account

```bash
DELETE /v1/client/banks/:publicId
```

Accounts waiting for activation cannot be disconnected.

```json
{
  "data": {
    "status": true,
    "message": "Xóa tài khoản ngân hàng thành công"
  },
  "statusCode": 200,
  "timestamp": "2026-08-12T14:27:45.000Z"
}
```
