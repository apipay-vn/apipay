# Bank Management

Use the bank management API to discover supported banks, connect accounts, complete verification, and manage linked accounts.

Base route:

```bash
/v1/client/banks
```

## Supported banks

| Bank       | Short name | BIN      | Account types                          |
| ---------- | ---------- | -------- | -------------------------------------- |
| ACB        | `ACB`      | `970416` | personal, business, household business |
| MB Bank    | `MBB`      | `970422` | personal, business, household business |
| BIDV       | `BIDV`     | `970418` | personal, business, household business |
| OCB        | `OCB`      | `970448` | personal, business, household business |
| VietinBank | `ICB`      | `970415` | personal, business, household business |
| VIB        | `VIB`      | `970441` | personal, business, household business |
| Sacombank  | `STB`      | `970403` | personal, household business           |
| VPBank     | `VPB`      | `970432` | personal                               |
| PGBank     | `PGB`      | `970430` | personal, business, household business |
| Shinhan    | `SHBVN`    | `970424` | personal, business                     |
| Co-opBank  | `COOPBANK` | `970446` | personal, business, household business |
| Vietcombank| `VCB`      | `970436` | business, household business           |

Use `GET /v1/client/banks/available` to retrieve the live bank catalog before showing a bank picker.

## 1. List available banks

```bash
GET /v1/client/banks/available
```

### Response

```json
{
  "status": true,
  "message": [
    {
      "bankCode": "MBB",
      "bankName": "MB Bank",
      "bankBin": "970422",
      "shortName": "MBB",
      "logoUrl": "https://example.com/mbbank.png"
    }
  ]
}
```

## 2. Connect a bank account

```bash
POST /v1/client/banks
```

### Request body

```json
{
  "bankBin": "970422",
  "bankName": "MB Bank",
  "accountType": "personal-account",
  "accountNumber": "24550721",
  "accountName": "PHAM THANH DANH",
  "mobile": "0858838502",
  "identity": "012345678901"
}
```

### Fields

| Field           | Type   | Required    | Description                                                              |
| --------------- | ------ | ----------- | ------------------------------------------------------------------------ |
| `bankBin`       | string | Yes         | BIN returned by the available banks endpoint                             |
| `bankName`      | string | Yes         | Bank display name                                                        |
| `accountType`   | string | Yes         | `personal-account`, `business-account`, or `business-household-account`  |
| `accountNumber` | string | Yes         | Bank account number                                                      |
| `accountName`   | string | Yes         | Account holder name in uppercase without accents                         |
| `mobile`        | string | Yes         | Phone number registered with the bank                                    |
| `identity`      | string | Yes         | Citizen ID for personal accounts, or tax code for business account types |
| `acbUserId`     | string | Conditional | ACB OneBiz username for ACB business and household business accounts     |

Sacombank accepts `personal-account` and `business-household-account`.
Shinhan accepts `personal-account` and `business-account`.
VPBank accepts `personal-account` only (business and household business accounts are not supported).

VietinBank transactions have no transfer content; contact support for more details.

### Response when OTP is required

```json
{
  "status": true,
  "OTP": 1,
  "type": "openapi",
  "message": "Vui lòng nhập mã OTP để hoàn tất liên kết tài khoản ngân hàng",
  "bank": {
    "publicId": "bnk_abc123",
    "vaNumber": null,
    "status": "PENDING"
  }
}
```

Submit the verification code to the confirm OTP endpoint.

### Response when the account is active

```json
{
  "status": true,
  "OTP": 0,
  "type": "openapi",
  "message": "Liên kết tài khoản ngân hàng thành công",
  "bank": {
    "publicId": "bnk_abc123",
    "vaNumber": "DANH001",
    "status": "ACTIVE"
  }
}
```

### Response when manual activation is required

```json
{
  "status": true,
  "activationRequested": true,
  "OTP": 0,
  "type": "openapi",
  "message": "Tài khoản đã được kết nối và đang chờ xác minh. Quá trình kích hoạt có thể mất đến 24 giờ.",
  "bank": {
    "publicId": "bnk_abc123",
    "vaNumber": null,
    "status": "PENDING"
  }
}
```

Manual activation applies to:

- MB Bank, OCB, and VIB business or household business accounts
- BIDV, VietinBank, and Shinhan Bank business accounts
- Vietcombank business and household business accounts

ApiPay contacts the account owner to complete activation.

## 3. Confirm OTP

```bash
POST /v1/client/banks/confirm-otp
```

### Request body

```json
{
  "bankBin": "970422",
  "accountNumber": "24550721",
  "otpNumber": "123456"
}
```

### Response

```json
{
  "status": true,
  "message": "Xác nhận ngân hàng thành công"
}
```

## 4. List linked bank accounts

```bash
GET /v1/client/banks
```

### Response

```json
{
  "status": true,
  "message": [
    {
      "id": 12,
      "publicId": "bnk_abc123",
      "bankName": "MB Bank",
      "bankShortName": "MBB",
      "accountNumber": "24550721",
      "accountName": "PHAM THANH DANH",
      "vaNumber": "DANH001",
      "status": "ACTIVE",
      "manualActivationPending": false,
      "hasTransactions": false,
      "createdAt": "2026-04-25T10:00:00.000Z"
    }
  ]
}
```

### Account statuses

- `ACTIVE`: enabled and ready to use
- `INACTIVE`: disabled
- `PENDING`: waiting for OTP or manual activation

`manualActivationPending` is `true` while ApiPay is processing a manual activation request.

`hasTransactions` is `true` once the account has recorded at least one transaction. Banks with transactions cannot be deleted directly through the API; contact support@apipay.vn if you need to change your bank.

## 5. Get a bank account

```bash
GET /v1/client/banks/:publicId
```

### Success response

```json
{
  "status": true,
  "message": {
    "publicId": "bnk_abc123",
    "bankName": "MB Bank",
    "bankShortName": "MBB",
    "accountNumber": "24550721",
    "accountName": "PHAM THANH DANH",
    "vaNumber": "DANH001",
    "status": "ACTIVE",
    "manualActivationPending": false,
    "hasTransactions": false
  }
}
```

### Not found response

```json
{
  "status": false,
  "message": null
}
```

```json
  "inactive": 1,
  "pending": 0

```

## 7. Toggle bank status

```bash
PATCH /v1/client/banks/:publicId/status
```

The endpoint switches the linked account between `ACTIVE` and `INACTIVE`.

### Response

```json
{
  "status": true,
  "message": "Cập nhật trạng thái ngân hàng thành công",
  "newStatus": 1
}
```

`newStatus` is `1` for active and `0` for inactive. Accounts waiting for activation cannot be toggled.

## 8. Disconnect a bank account

```bash
DELETE /v1/client/banks/:publicId
```

The account is disconnected immediately unless the bank requires OTP confirmation.

### Response when OTP is required

```json
{
  "status": true,
  "OTP": 1,
  "type": "openapi",
  "message": "Vui lòng nhập mã OTP để xác nhận xóa ngân hàng"
}
```

Accounts waiting for manual activation cannot be disconnected until ApiPay finishes processing the request.

## 9. Confirm bank disconnection

```bash
POST /v1/client/banks/:publicId/confirm-delete
```

### Request body

```json
{
  "otp": "123456"
}
```

### Response

```json
{
  "status": true,
  "message": "Xóa tài khoản ngân hàng thành công"
}
```
