## Bank Codes

When creating anonymous payment links, use bank codes:

```json
{
  "bankCode": "MB",
  "accountNumber": "0123456789"
}
```

## Supported QR Formats

ApiPay generates QR codes in VietQR standard, compatible with all banks:

- **VietQR** - QR standard from VietQR API
- **Bank Transfer** - Traditional transfer information

Users can scan using:
- Bank apps (Vietcombank Mobile, MB Bank, ACB, etc.)
- Payment apps (VietQR, MoMo, ZaloPay, etc.)
