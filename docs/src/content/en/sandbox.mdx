# Sandbox & Live Test

There are two ways to test before taking real payments:

- **Live Test**: simulates a transaction on your real bank account and sends it to your real webhook. No money moves and your live data is untouched.
- **Sandbox**: a separate environment with test API keys, a test bank and test payment requests.

Both sign webhooks with the same `ApiPay-Signature` header as live.

---

## Live Test

Use Live Test to check your real webhook endpoint without waiting for a bank transfer. You need an active plan and at least one connected bank account.

1. Open **Sandbox Mode** in the dashboard and keep the toggle on **Live Test**.
2. Pick a bank account, enter an amount, content and the receiving webhook (every webhook that applies to that bank, or one specific webhook).
3. Click **Create and trigger**. The result shows the payload and each webhook's response code and body.

### Live Test payload

Same as a live payload, plus `"sandbox": true` and `"liveTest": true`. The reference code starts with `LVT-`.

```json
{
  "event": "transaction.in",
  "sandbox": true,
  "liveTest": true,
  "data": {
    "transactionId": "clxyz123abc",
    "referenceCode": "LVT-1755298200000-A1B2C3D4",
    "amount": "50000",
    "type": "IN",
    "content": "LIVETEST-ORDER-001",
    "transactionDate": "2026-08-15T10:30:00.000Z",
    "bankAccountPublicId": "bnk_abc123",
    "gateway": "970422",
    "vaNumber": null,
    "accountNumber": "0123456789"
  }
}
```

Every Live Test event has `sandbox: true`, so one check is enough:

```javascript
app.post("/webhooks/apipay", express.raw({type: "*/*"}), (req, res) => {
  // Verify the signature first, see the Webhooks page
  const {event, sandbox, data} = JSON.parse(req.body.toString("utf8"));

  if (sandbox) {
    console.log("[test] test event:", event);
    return res.status(200).json({received: true});
  }

  if (event === "transaction.in") {
    // Fulfill the real order
  }

  res.status(200).json({received: true});
});
```

You can clear your Live Test history at any time in the dashboard.

## Sandbox

Sandbox behaves like live, but no real money moves and your live data is never touched. No paid plan needed, just a verified account.

1. Open **Sandbox Mode** in the dashboard and switch the toggle to **Sandbox**. The dashboard now shows sandbox data only.
2. Add a sandbox bank, register a sandbox webhook and create a test API key.
3. Call the API as usual with the test key, then simulate a payment.

| Resource | How to tell |
| -------- | ----------- |
| Test API key | `accessKey` starts with `ak_test_` |
| Sandbox bank | `publicId` starts with `test_bank_` |
| Test payment request | `publicId` starts with `test_pr_` |
| Sandbox transaction | `publicId` starts with `test_txn_` |

### Simulate a payment

```bash
POST /v1/payment-requests/:publicId/pay
```

Marks a sandbox payment request as paid and sends the webhook to your sandbox webhooks. No authentication, no body. Only `publicId` values starting with `test_pr_` are accepted; anything else returns `400`.

```bash
curl -X POST https://app.apipay.vn/v1/payment-requests/test_pr_abc123/pay
```

```json
{
  "data": {
    "publicId": "test_pr_abc123",
    "status": "COMPLETED",
    "transaction": {
      "publicId": "test_txn_a1b2c3d4e5f6a7b8",
      "amount": "50000",
      "content": "TEST-ORDER-001",
      "sandbox": true
    },
    "sandbox": true
  },
  "statusCode": 201,
  "timestamp": "2026-08-15T10:30:00.000Z"
}
```

You can also simulate from the dashboard: create a manual transaction on the **Transactions** page, or open the payment page of a `test_pr_` request and use the test pay button.

### Sandbox payload

Sandbox webhooks are shorter than live payloads and carry `"sandbox": true`:

```json
{
  "event": "transaction.in",
  "sandbox": true,
  "created": "2026-08-15T10:30:00.000Z",
  "data": {
    "publicId": "test_txn_a1b2c3d4e5f6a7b8",
    "amount": "50000",
    "content": "TEST-ORDER-001",
    "type": "IN",
    "status": "SUCCESS"
  }
}
```

### Clear history and reset

- **Clear history**: removes sandbox payment requests, transactions and webhook delivery history. Your sandbox bank, webhooks and API keys stay.
- **Reset sandbox**: removes all sandbox data, including API keys, bank and webhooks.

## Tips

- Use [Webhook.site](https://webhook.site) or [ngrok](https://ngrok.com) to receive webhooks on a local machine.
- Sandbox uses the same API as live; only the API key changes.
