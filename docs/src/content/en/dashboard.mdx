# Dashboard Guide

The ApiPay dashboard (my.apipay.vn) is where you manage banks, payments and integrations. This page shows where each task lives.

---

## Sidebar

| Group | Items |
|-------|-------|
| Overview | Overview, Transactions, Notifications, Pricing, Integrations, System Status |
| Payment Gateway | Banks, Webhooks, Create QR Code, Payment Requests |
| Integrations | Sandbox Mode, Notification Channels, Custom Domains, Payment Speaker, Stores, Web App (API Keys, Vibe Code, MCP Server, Commerce, WHMCS, WooCommerce, HostBill, Google Sheets) |
| Account | Invoices, Affiliates, Settings (Account, Appearance, Help) |
| Support | Documentation, Contact, Meet Appi |

Press `Ctrl + K` (or `Cmd + K` on Mac) to jump to any page.

---

## Overview

The first page after you sign in. It shows your active banks and webhooks, total transactions, total inflow, transaction charts over time and by bank, and your most recent transactions.

---

## Transactions

Every transaction on your connected banks, with date, bank, amount, content and status.

- Search by reference or content, filter by bank and status.
- Click a transaction to see its details.
- Export a date range to CSV or Google Sheets.

---

## Payment requests

Create a payment link with a QR code to send to your customer.

1. Open **Payment Requests** and click **Create Link**.
2. Pick a bank, enter the amount and transfer content. Title, redirect URL and custom domain are optional.
3. Copy the link and send it to your customer.

Each request is **Active**, **Completed**, **Expired** or **Deleted** (cancelled). To set a default title and redirect URL, click **Payment Page** at the top of the page.

Creating them through the API? See the [Payment Requests API](/en/api/payment-requests).

---

## Banks and webhooks

- **Banks**: connect accounts, set a nickname, turn an account on or off. See [Connect Banks](/en/connect-banks) and [Bank Management](/en/banking).
- **Webhooks**: add a URL that receives transaction notifications, view the delivery log and resend when needed. See [Webhooks](/en/api/webhooks).

## Integrations

| Item | Use it to |
|------|-----------|
| Sandbox Mode | Test your integration without moving real money. See [Sandbox](/en/sandbox) |
| Notification Channels | Get transaction alerts on Telegram, Slack, Discord, Lark or email |

| Stores | Group receiving accounts by store and invite staff. See [Stores and Staff](/en/stores-staff) |
| Web App → API Keys | Create the API key your system uses to call ApiPay |
| Web App → Commerce | Products, prices and reusable payment links. See [Commerce](/en/commerce) |
| Web App → WHMCS, WooCommerce, HostBill, Google Sheets | Connect the platform you already use |

## Account

- **Pricing**: pick a plan, see quota usage and renew. See [Plans and Billing](/en/subscription).
- **Invoices**: invoices for your plan payments.
- **Affiliates**: your referral code and commission. See [Affiliates](/en/affiliates).
- **Settings → Account**: the **Profile** tab (name, phone, business details), **Security** (password, sign-in history, sign out of all devices) and **Credentials** (two-factor authentication, [passkeys](/en/passkeys)).
- **Settings → Appearance**: light or dark theme, language, font and sidebar style.
